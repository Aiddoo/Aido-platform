# 1.17.0 사용자 상황 확인표

캘린더 가져오기를 기기에서 만들어 보는 표다. 결과·근거 칸에는 실제로 확인한 값만 적는다. 지금은 모두 `미확인`이다. 기기마다 캘린더에 일정을 미리 넣은 뒤 iPhone → iPad → 접은 Duo 순서로 한 대씩 하고, 라이트·다크 × 글꼴 최소·기본·최대 × ko·en을 돌린다.
