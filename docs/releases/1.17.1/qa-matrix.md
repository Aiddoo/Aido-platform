# 1.17.1 사용자 상황 확인표

버그 수정과 구조 정리를 기기에서 확인하는 표다. 결과·근거 칸에는 실제로 확인한 값만 적는다. 2026-11-26 iPhone 시뮬레이터(iPhone 18 Pro, 로컬 Release 빌드, 로컬 API)의 Maestro smoke만 채웠고 나머지는 `미실행`이다. iPhone → iPad → 접은 Duo → Android 순서로 한 대씩 하고, 라이트·다크 × 글꼴 최소·기본·최대 × ko·en을 돈다.
