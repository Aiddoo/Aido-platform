# 1.17.1 사용자 상황 확인표

버그 수정과 구조 정리를 기기에서 확인하는 표다. 결과·근거 칸에는 실제로 확인한 값만 적고 나머지는 `미실행`이다. 2026-11-26~27에 시뮬레이터·에뮬레이터 한 대씩 로컬 Release 빌드(개발 변형)와 로컬 API로 확인했다. 기기는 iPhone 18 Pro, iPad Pro 13, iPhone Duo(접힘), Android 폰(Pixel 6 꼴, Android 16)이고 모두 라이트·기본 글꼴이다. iOS는 한국어, Android는 영어로 돌았다.

## 기기 QA에서 찾아 고친 것

| 무엇                                                          | 어디            | 처음부터 있었나 |
| ------------------------------------------------------------- | --------------- | --------------- |
| 좁은 화면의 메모 카드가 iOS 접근성 트리에 없다                | iPhone·접은 Duo | 1.17.0에도 있음 |
| 카테고리 관리의 둘째 줄부터 수정·삭제 버튼이 줄 밖에 그려진다 | Android         | 1.17.0에도 있음 |
| 애니메이션을 끈 기기에서 날씨의 지역·기온·요약이 비어 있다    | Android         | 1.17.0에도 있음 |

## 찾았지만 고치지 않은 것

- **Android 에뮬레이터에서 날씨 화면을 열면 앱이 네이티브 충돌로 죽는 일이 있다.** 이 stack의 코드 12번 중 8번, 1.17.0 코드로 만든 빌드 15번 중 4번이라 이 버전이 만든 문제는 아니다. 실기기에서도 나는지는 확인하지 못했다(#1785).
- 새 계정이 첫 할 일을 완료하면 뜨는 마케팅 알림 동의 시트 위에 안내 말풍선이 겹쳐 그려진다(Android에서 확인, #1785).
- `todo/complete-offline-rolls-back` 흐름은 에뮬레이터에서 볼 수 없다. 비행기 모드에서도 `adb reverse`로 로컬 API에 닿는다.
