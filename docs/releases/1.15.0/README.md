## 요약

- **말로 할 일 만들기**: 할 일 추가 시트에서 말하면 글자로 바꾸고, AI가 계획을 만들어 사용자가 고른 것만 저장한다.
- **말로 메모하기**: 긴 녹음을 글자로 바꾼 뒤 요약·핵심 포인트·할 일로 정리한다.
- **음성 인식**: iOS 빠른 말하기는 Apple 서버 인식이다. 말로 메모는 기기 인식을 우선한다. Android는 언어 모델이 있으면 기기에서 인식한다. 기기에서 인식할 수 없으면 Apple·Google 음성 인식이 처리할 수 있다.
- **녹음과 글자**: 녹음 파일은 기기에 저장하고 아이두 서버로 보내지 않는다. 서버는 글자만 받아 정리하고 전사를 저장하지 않는다.
- **AI 순서**: Claude → Gemini → OpenAI. 앞 업체가 실패하면 다음 업체로 넘어간다.
- **반복 할 일**: 규칙(`TodoSeries`)으로 저장하고 회차는 앞으로 90일 치만 만든다. 매일 03:10 KST 작업이 채운다.
- **떠 있는 시각**: 한국에서 만든 오전 10시는 미국에서도 오전 10시이고 알림도 현지 10시에 울린다.
- **한도**: 규칙은 `PLAN_CATALOG` 한 곳이고, 다 쓴 안내는 `PremiumUpsellBottomSheet` 하나다. 사용량·초기화 날짜·무료 → 프리미엄 숫자를 보이고, 나중에를 고른 기능은 그날 토스트로만 알린다. 친구 한도는 초대가 주 버튼이고, 카테고리 한도는 이름을 쓰기 전에 막는다. 할 일 추가·완료는 막지 않는다.
- **결제 화면·무료 체험**: 막힌 기능을 맨 위에 두고 연간을 미리 고른다. 연간 첫 구독은 스토어가 대상이라고 할 때만 2주 무료 체험(일정·버튼 아래 정기결제 안내)을 보인다. 체험이 끝나기 3일 전에 서버가 알림을 보낸다. 2025-02-14 시행 전자상거래법 개정으로 무료 → 유료 전환 전 30일 안에 받은 동의가 있어야 해서, 결제 시트의 동의가 그 안에 들도록 한다.
- **권한·동의**: 가입 직후 알림 화면 한 장으로 묻고, 위치는 날씨를 열 때, 마이크는 누를 때 묻는다. 알림이 꺼진 채 할 일 시간을 정하면 그 자리에서 알린다. 광고성 푸시는 동의한 사람에게만 "(광고)" 표기와 수신 거부 방법을 붙여 보낸다. 소셜 로그인 아래에 약관 안내를, 이메일 가입에 필수·선택 동의를 둔다.
- **내 정보 두 칸**: 넓은 화면에서 왼쪽 메뉴를 두고 오른쪽만 바꾼다. 설정 화면은 `SettingsListGroup`·`SettingsScreenLayout` 한 벌로 다시 짰다.
- **기타**: 답글 숨기기 버그 수정, 알림 아이콘 재디자인.

## 디자인 결정

- **소리 표현**: 빠른 말하기는 주황 구와 양쪽 막대다(Skia `RuntimeEffect`). 높이는 84pt로 고정한다. 프레임이 30fps 아래로 2초 이어지면 가벼운 구로 바꾼다. 모션 줄이기와 듣기 멈춤에서는 프레임 콜백을 끈다. 말로 메모는 중요 표시 깃발 때문에 타임라인 파형을 유지한다.
- **말풍선(코치마크)**: heroui-native `Popover`와 `Popover.Close`만 둔다. 행동 버튼은 두지 않는다. 대상을 누르거나 닫으면 끝난다.
- **시트 표시 라벨**: 할 일 추가 시트의 라벨은 `AiIcon` + "AI로 할 일 만들기 ⓘ" + 남은 횟수 알약이다. ⓘ는 AI가 하는 일, 알아듣는 말의 예, 남은 횟수와 다시 채워지는 날, "잘 안 되면 횟수는 차감되지 않아요"를 보여준다. 값은 서버 스냅샷(`GET /v1/entitlements`)에서 온다.
- **새로운 기능**: 캠페인 `feature-discovery-2026-12`는 2단계다. ① 말로 할 일 만들기, "지금 말해 보기"로 할 일 추가 시트와 마이크 말풍선으로 이동 ② 말로 메모하기, "메모 시작"으로 한도·동의·권한을 지나 녹음으로 이동. 마이 메뉴에서 출시 목록을 언제든 다시 연다. 친구 초대는 1.14 항목으로 옮겼다(초대 기능이 꺼지면 숨김).
- **계획 검토**: 할 일 목록 행을 재사용하고 왼쪽 체크로 추가 여부를 고른다. 이미 있는 할 일은 "이미 있어요" 표시와 함께 기본 꺼짐이다. 행을 누르면 기존 칩·시트로 고친다. 추가 버튼은 아래에 고정하고 카드만 스크롤한다. 내용을 끌어도 시트는 움직이지 않는다. 바깥 탭과 Android 뒤로 가기는 고를 카드가 있으면 버리기 전에 묻는다. 손잡이 끌기는 묻지 않고 닫는다([미룬 일](#출시-후로-미룬-일)).
- **알림 아이콘**: 읽지 않은 알림이 있으면 채운 종 + 주황 점이다.
- **범위 선택**: 할 일 수정은 날짜·반복 선택과 같은 떠 있는 시트로, 더보기·시간·카테고리는 쓰던 시트 안에서 묻는다.
- **3개월 안내**: 달력 아래 한 곳에만 보인다. 월 보기는 그 달이 일부라도 90일을 넘으면, 주 보기는 고른 날이 넘으면 보인다.
- **메모**: 메모 화면은 아래에서 올라온다(`slide_from_bottom`, 말로 남긴 메모와 같다). 메뉴 항목은 `MenuActionItem`(주황 아이콘)이다. 메모 탭의 말로 남긴 메모는 최근 3개만 보이고 넘치면 "전체 보기"로 간다.
- **방향**: `orientation`은 `portrait`다. iPhone은 세로, iPad는 네 방향을 모두 지원한다. Android 매니페스트도 세로다.

### AI 표시

- AI를 쓰는 곳에 `AiIcon`을 둔다. 무료 사용자에게 남은 횟수를 함께 보인다.
- 마이 탭의 `QuotaSummary`가 이번 달 남은 횟수를 모아 보여 준다. 프리미엄·관리자에게는 숨긴다.
- 쓸 때마다 묻는 창은 없다. 처음 한 번 AI 동의를 묻고, 다 쓰면 프리미엄 안내 시트(`PremiumUpsellBottomSheet`)를 띄운다.
- 말로 메모 정리 버튼 아래에 "1번 사용 · 이번 달 N번 남음"을 보인다.

### 넓은 화면 두 칸

- **내 정보**: 친구·배지·리포트·설정·새로운 기능 목록을 URL을 바꾸지 않는 마이 탭 안 그룹 `(tabs)/(mypage)`의 Stack에 두어 하위 화면에서도 탭 바가 남는다. 넓은 화면은 `AdaptivePane`으로 왼쪽 메뉴가 그대로 있고 오른쪽 Stack만 바뀐다. 접힌 화면은 push다. 세부는 [클라이언트 문서](../../../apps/mobile/docs/releases/1.15.0-client.md#넓은-화면)에 있다.
- **`SplitView`·`ArrangementView`**: 시험했으나 넣지 않았고 다음 버전에 다시 검토한다. 이유는 [AdaptivePane 문서](../../../apps/mobile/src/shared/ui/adaptive-pane/adaptive-pane.md#splitviewarrangementview를-쓰지-않는-이유)에 있다.

## 한도·정책 (`PLAN_CATALOG`)

| 기능                              | 무료                         | 프리미엄                                      |
| --------------------------------- | ---------------------------- | --------------------------------------------- |
| AI 할 일 만들기 (글·말·메모 공통) | 월 10회                      | 월 1,000회(공정 사용 상한, 문구는 "넉넉하게") |
| 말로 메모하기                     | 월 3회, 회당 3분             | 월 100회, 회당 30분                           |
| 녹음 다시 듣기·핵심 포인트 이동   | 가능                         | 가능                                          |
| 친구                              | 5명(조건을 채운 초대마다 +1) | 무제한 (카탈로그 `premium: null`)             |
| 카테고리                          | 3개                          | 30개                                          |
| 콕 찌르기·응원                    | 하루 3회씩                   | 무제한 (카탈로그 `premium: null`)             |

- 정책 판단은 서버가 한다. 앱은 서버 값을 읽고 그린다.
- 관리자(ADMIN)는 횟수 한도가 없고 사용량만 장부에 남는다. 성능·안정성 상한(반복 30개, 메모 20개, 하위 할 일 20개, 글자 수)은 등급과 무관하다.
- 차감은 AI 호출 전에 예약한다. 실패·시간 초과·전 업체 장애·빈 결과면 한 번만 환불한다. 저장(적용)은 차감하지 않는다.
- 빠른 계획은 할 일 0개면 환불한다. 녹음 정리는 요약이나 핵심 내용이 있으면 할 일 0개여도 차감한다.
- 같은 `Idempotency-Key`는 한 번만 차감한다. 자세한 규칙은 [AI 문서](../../../apps/api/docs/ai.md#계획-생성과-적용voice)에 있다.

## 반복 할 일

- 회차는 앞으로 90일(`VISIBLE_AHEAD_DAYS`)까지 만든다. 진행 중 반복은 등급과 상관없이 30개까지다(`TODO_0842`). 새 반복의 지난 회차는 366개까지다(넘으면 `TODO_0845`).
- 규칙을 바꾸면 이 회차부터 나눈다. 첫 회차에서 고치면 나누지 않는다.
- 제목·카테고리·공개·시간·체크리스트는 나누지 않고 제자리에서 고친다. 완료한 회차의 내용은 바꾸지 않는다.
- 휴면: 무료 사용자가 60일 넘게 쓰지 않으면 회차 채우기와 반복 알림을 멈추고 한 번 안내한다. 돌아오면 오늘부터 이어 만든다.

## AI 순서

- Claude(`claude-haiku-5-5`) → Gemini(`gemini-3.1-flash-lite`) → OpenAI(`gpt-6-luna`). 키 등록과 순서 확정은 사용자가 한다.
- Claude 크레딧이 소진되면(HTTP 402 `billing_error`) 자동으로 Gemini로 넘어간다.
- 1순위 확정 기준은 `pnpm ai:eval`의 날짜 0.97·제목 0.9·겹침 판정 0.9다. **기준 통과 판단은 측정 전이다.** 업체별 지연 실측은 [AI 문서](../../../apps/api/docs/ai.md#업체-체인폴백회로)에 있다.

## 호환

- 출시 앱 OpenAPI fingerprint(`test/e2e/fixtures/released-v1*`)는 바뀌지 않아야 한다. 기존 필드와 코드는 유지하고 추가만 한다.
- AI 동의 버전은 `2026-11-04`다. 1.13·1.14 앱의 기존 동의는 Google만 허용한다. 1.15 앱은 이전 안내에 동의한 사람에게 바뀐 안내를 계정마다 한 번 보여 준다. "나중에"면 서버로 보내지 않고 이전 동의 범위로 이어 간다.
- 새 오류 코드: `AI_1312`(녹음이 너무 길어요, 422), `AI_1313`(녹음 정리 한도, 429), `AI_1314`(같은 요청 처리 중, 409), `AI_1315`(계획이 올바르지 않아요, 422), `AI_1316`(`Idempotency-Key` 없음, 400), `AI_1318`(같은 키로 다른 요청, 422), `TODO_0841`~`TODO_0846`(반복 할 일). 차감하지 않은 오류는 공개 상세에 `charged: false`를 싣는다.

## 배포 전 확인

- **AI 키**: 운영 env에 키 3개를 넣고 `AI_PROVIDER_ORDER`를 정한다. 값은 문서에 쓰지 않는다. Claude 키는 워크스페이스 키로 새로 발급한다.
- **마이그레이션**: 위 8개를 적용한다. 건수 확인 쿼리는 서버 배포 문서를 따른다.
- **기능 소개 캠페인**: `FEATURE_DISCOVERY_CAMPAIGN_ID`를 앱에 번들된 `feature-discovery-2026-12`로, `FEATURE_DISCOVERY_MIN_APP_VERSION`을 `1.15.0`으로, `FEATURE_DISCOVERY_LAUNCHED_AT`을 1.15.0 배포 시각으로 맞춘다. `.env.example`의 `FEATURE_DISCOVERY_LAUNCHED_AT`은 예시 값이다.
- **경보**: [관측 문서](../../../apps/api/docs/observability.md#sentry-무료-플랜-운영)의 태그로 Sentry 알림 규칙을 만든다. 없으면 경보가 사람에게 가지 않는다.
- **권한**: 최종 Release APK를 `aapt2 dump permissions`로, Production `Info.plist`를 직접 확인한다. `app.config.ts` 평가 결과는 [개인정보 라벨](privacy-label.md#권한-점검)에 있다.
- **무료 체험**: 앱은 스토어가 준 기간을 그대로 보이므로 콘솔 값이 곧 화면 문구다. 1.14.2 결제창에 고지 없이 체험이 뜨지 않도록 1.15.0 승인 직후에 켠다. 켜기 전에는 앱이 일반 가격만 보인다.
  1. App Store Connect 연간 구독 > 구독 가격 > 소개 혜택: 모든 국가·지역, 종료일 없음, 신규 구독자, 유형 "무료", 기간 "2주".
  2. Play Console 연간 기본 요금제 `yearly-base` > 혜택 추가: ID `annual-trial-2w`, 자격 "신규 고객", 무료 체험 단계 2주(주 단위. 14일로 넣으면 앱에 "14일 무료"로 보인다), 활성화. 임시 저장한 `annual-trial-1m`은 활성화하지 않고 삭제한다.
  3. 콘솔에 미리 저장한 앱 설명·구독 설명의 체험 문장을 [스토어 문구](store-listing.md)의 2주 문장으로 바꾼다.
- **심사 메모**: 데모 계정(무료 플랜, 기본 카테고리 2개, 가입 1일 경과)을 채워 스토어에 넣는다. 영어 메모는 계정을 비운 상태로 3,959자라 계정 값은 합쳐 41자 안이어야 한다.
- **스토어 문구**: [스토어 문구](store-listing.md)를 listing에 옮기면서 `apps/mobile/store-metadata/1.15.0/release.json`을 만든다. 이 파일이 없으면 `store:check`와 `test:store-listing`이 실패한다.
- **약관**: 개인정보처리방침·약관의 위탁 업체 목록과 음성 처리 조항을 갱신한다(랜딩, 별도 저장소, 법무 검토 필요).

### 코드 규칙

- **모델 계약 import**: `CLIENT_OWNED_MODEL_PATHS`에 없는 모델은 아직 `@aido/api` 계약을 import한다.
- **큰 파일 분해**: 앱 코드에 500줄 이상인 파일이 12개다. 가장 큰 파일은 `add-todo-bottom-sheet.tsx`(870줄)다.
- **Facade 별칭**: `XPolicy`의 키와 함수 이름이 다른 곳 80곳(`isStale: isReportStale`).
- **RN `Image`**: `react-native`의 `Image`를 import하는 앱 파일 15개.
- **테스트 주석**: 규칙과 다른 GWT 주석. `// Given - 설명`·`// Given: 설명` 꼴 1,693건(서버 1,540, 앱 153), `// When / Then` 합본 566건(서버 397, 앱 169). 기존 테스트를 일괄 교체하지 않으므로 손댈 때 고친다.
- **RRULE**: 반복 규칙을 표준 RRULE 형식으로 옮기는 일. 지금은 `TodoSeries` 필드로 저장한다.
- **Reanimated `.value =`**: `.get()`·`.set()`으로 바꾸지 않은 16곳(6개 파일).
- **RN `Pressable`**: `react-native` import 17개(앱 코드 4, 테스트 13).
- **빈 catch**: `.catch(noop)` 17곳과 빈 화살표 `.catch` 14곳, 합쳐 31곳. 실패가 다른 곳에 보고되는지 확인한다.
- **감싼 fallback**: `fallback={(props) => …}`로 감싼 시트·상세 pane 15곳(시트 13, 상세 pane 2).
- **`memo-list`**: 메모 탭 목록은 무한 조회를 `.map`으로 그린다. `FlashList`를 적용하지 않았다.
- **`TodoList`**: 할 일 목록도 `.map`으로 그린다. 하루 할 일이 많을 때의 탭 이동 수치를 Release로 잰 뒤 `FlashList` 적용을 정한다.
- **옛 포트 이름**: 서버 날씨 포트의 `KmaForecastTiming` 등 공급자 이름이 남았다.
- **미사용 export**: 1.15.0 이전부터 있던 것은 지우지 않았다.
- **왼쪽 메뉴 28pt 차이**: 딥링크로 첫 시작하면 내 정보 왼쪽 메뉴의 위 여백이 탭에서 들어올 때와 28pt 다르다.

### 최종 QA: 듣기와 시트

- 듣기 중에 앱 안 배너를 탭하면 들은 글자를 잃는다.
- 다시 정리가 또 실패하면 입력 칸이 한 줄로 줄어든다.
- 계획을 버릴 때 보내는 분석 이벤트가 없다.
- 합친 제목이 200자를 넘으면 Android에서 잘릴 수 있다. 실패 단계 입력 칸만 `maxLength`가 없다.

### 최종 QA: 성능과 관측

- 하루 200개 할 일의 탭 이동은 Release 빌드에서 다시 잰다.
- `useFrameCallback`의 `startTime` 오류가 1회 있었다. Sentry에서 지켜본다.

### 최종 QA: 화면과 동작

- 알림 권한 안내가 결정 전까지 콜드 스타트마다 뜬다.

### 최종 QA: 글자와 문구

- 단어 끊김이 남았다. `lineBreakStrategyIOS`만 쓰는 곳이 93곳이라 Android에서는 음절 사이에서 끊길 수 있다.
