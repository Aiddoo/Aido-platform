# 1.15.0: 말로 할 일 만들기·말로 메모하기·반복 할 일·AI 폴백·한도 정책

**상태: 구현 완료, 출시 전 QA 진행 중.** 측정하지 않은 값은 "측정 전"으로 둔다. 스토어 심사 제출은 아직 하지 않았다.

클라이언트 세부는 [1.15.0 클라이언트](../../../apps/mobile/docs/releases/1.15.0-client.md), 서버 변경 목록은 [CHANGELOG](../../../apps/api/CHANGELOG.md), 되돌리기는 [서버 배포 문서](../../../apps/api/DEPLOYMENT.md)를 따른다. 스토어 문구 초안은 [store-listing.md](store-listing.md), 개인정보 라벨 메모는 [privacy-label.md](privacy-label.md), 이벤트 정의는 [analytics 측정 계획](../../../apps/mobile/docs/analytics-measurement-plan.md)을 따른다.

## 요약

- 할 일 추가 시트에서 말하면 글자로 바꾸고(iOS는 Apple 서버 인식, Android는 기기 인식 우선), AI가 할 일 계획을 만들어 사용자가 확인한 것만 저장한다.
- 긴 녹음은 같은 경로로 글자로 바꾼 뒤 요약·핵심 포인트·할 일로 정리한다. 녹음 파일은 기기에 저장하고 아이두 서버로 보내지 않는다.
- 서버는 글자만 받아 정리하고 전사를 저장하지 않는다. AI 순서는 Claude → Gemini → OpenAI이며, 앞 업체가 실패하면 다음 업체로 넘어간다.
- 반복 할 일을 규칙(`TodoSeries`)으로 저장하고 회차는 앞으로 90일 치만 실제 행으로 만든다. 매일 03:10 KST 작업이 채운다.
- 결제·한도 규칙을 `PLAN_CATALOG` 한 곳으로 모으고, 한도 안내를 `PremiumDialog` 하나로 통일한다.
- 답글 숨기기 버그를 고치고 알림 아이콘을 있음·없음이 분명하게 다시 디자인한다.

## 디자인 결정

- **빠른 말하기 원**: 차분한 주황 구(Skia `RadialGradient`)와 천천히 퍼지는 고리 2개. 크기는 음량에 따라 0.54~0.66R 사이에서만 부드럽게 바뀌고(스무딩 0.08), 모션 줄이기에서는 멈춘다.
- **말풍선(코치마크)**: heroui-native `Popover`(밝은 배경·테두리·화살표)와 `Popover.Close`만 둔다. "말해볼게요 / 다음에" 같은 행동 버튼은 두지 않는다. 대상을 누르거나 닫으면 끝난다.
- **시트 표시 라벨**: 할 일 추가 시트의 표시 라벨은 "AI로 할 일 만들기 ⓘ · N번 남음"이다. 무료 사용자에게만 남은 횟수를 보이고, 다 쓰면 "이번 달 다 씀"으로 바꾼다. "말로 할 일 만들기"는 마이크 접근성 라벨과 코치마크 제목이다. ⓘ 안내는 AI가 하는 일, 알아듣는 말의 예, 남은 횟수와 다시 채워지는 날, "잘 안 되면 횟수는 차감되지 않아요"를 보여준다. 값은 모두 서버 `featureQuota`에서 온다.
- **기능 소개 시트 3장**: ① 긴 실제 예문에 구간별 색 밑줄 ② 같은 색으로 결과 할 일 5개(매일 반복·요일 반복·기간·하위 할 일·비공개) ③ 녹음 파일은 서버로 보내지 않고, 무료 한 달 10번, 실패는 차감 없음. 마지막 장 "지금 말해볼게요"가 할 일 추가 시트와 마이크 말풍선으로 이어진다.
- **계획 카드 = 실제 목록 행**: 지금 할 일 목록 행을 그대로 재사용하고 오른쪽에 추가 여부 체크만 더한다. 이미 있는 할 일은 "이미 있어요" 표시와 함께 기본 꺼짐이다. 행을 누르면 기존 칩·바텀시트로 고친다.
- **알림 아이콘**: C안, 채운 종 + 주황 점(읽지 않은 알림이 있을 때).
- **한도 안내**: 기존 `PremiumDialog`를 재사용하고, 기능별 문구를 한 줄씩 나란히 쓴다.
- **범위 선택**: 할 일 수정은 날짜·반복 선택과 같은 떠 있는 시트로, 더보기·시간·카테고리는 쓰던 시트 안에서 묻는다. 모양은 같은 떠 있는 카드다.
- **3개월 안내**: 달력 아래 한 곳에만 보인다. 월 보기는 그 달이 일부라도 90일을 넘으면, 주 보기는 고른 날이 넘으면 보인다.
- **방향**: 스마트폰은 세로 고정을 유지한다. iPad·Mac·큰 Android 화면만 가로를 지원한다.

## 한도·정책 (`PLAN_CATALOG`)

| 기능                              | 무료             | 프리미엄                                      |
| --------------------------------- | ---------------- | --------------------------------------------- |
| AI 할 일 만들기 (글·말·메모 공통) | 월 10회          | 월 1,000회(공정 사용 상한, 문구는 "넉넉하게") |
| 말로 메모하기                     | 월 3회, 회당 3분 | 월 100회, 회당 30분                           |
| 녹음 다시 듣기·핵심 포인트 이동   | 가능             | 가능                                          |
| 친구 추가·콕 찌르기               | 무료 한도        | 무제한 (카탈로그 `premium: null`)             |

- 관리자(ADMIN)는 횟수 한도가 없고 사용량만 장부에 남는다. 성능·안정성 상한(반복 30개, 메모 20개, 하위 할 일 20개, 글자 수)은 등급과 무관하게 같다.
- 정책 판단은 서버가 한다. 앱은 `featureQuota`와 스냅샷을 읽고 그린다.
- 차감은 AI 호출 전에 예약하고, 실패·시간 초과·전 업체 장애·빈 결과면 한 번만 환불한다. 빠른 계획은 할 일 0개도 환불하고, 녹음 정리는 요약이나 핵심 내용을 돌려주면 할 일 0개여도 차감한다. 저장(적용)은 차감하지 않는다.
- 같은 `Idempotency-Key`는 한 번만 차감한다. 결과를 잃은 재요청은 추가 차감 없이 다시 만들어 200으로 답한다.

## 반복 할 일

- 회차는 앞으로 90일(`VISIBLE_AHEAD_DAYS`)까지 실제 행으로 만든다. 진행 중 반복은 등급과 상관없이 30개까지다(`TODO_0842`). 새 반복의 지난 회차는 366개까지다(넘으면 `TODO_0845`).
- 규칙을 바꾸면 이 회차부터 나누고, 첫 회차에서 고치면 나누지 않는다. 제목·카테고리·공개·시간·체크리스트는 나누지 않고 제자리에서 고친다. 완료한 회차의 내용은 바꾸지 않는다(모든 반복 삭제만 지운다).
- 휴면: 무료 사용자가 60일 넘게 쓰지 않으면 회차 채우기와 반복 알림을 멈추고 한 번 안내한다. 돌아오면 오늘부터 이어 만든다. 유료·관리자는 멈추지 않는다. 자세한 규칙은 [휴면·복귀](../../server/todo-series-dormancy.md)에 있다.

## AI 순서

- 순서: Claude(`claude-haiku-5-5`) → Gemini(`gemini-3.1-flash-lite`) → OpenAI(`gpt-6-luna`). 키 등록과 순서 확정은 사용자가 결정한다.
- Claude 크레딧이 소진되면(HTTP 402 `billing_error`) 자동으로 Gemini로 넘어간다.
- 한국어 날짜 정확도 기준(날짜 0.97, 제목 0.9, 겹침 판정 0.9)은 `pnpm ai:eval`로 측정한 뒤 1순위를 확정한다. **측정 전.**
- 비용·지연·정확도 숫자는 측정하기 전이라 이 문서에 쓰지 않는다.

## 호환

- 출시 앱 OpenAPI fingerprint(`test/e2e/fixtures/released-v1*`)는 바뀌지 않아야 한다. 기존 필드와 코드는 유지하고 추가만 한다.
- AI 동의 버전은 `2026-11-04`로 올라간다. 1.13·1.14 앱의 기존 동의는 Google만 허용하고 그대로 동작한다. 1.15 앱은 이전 안내에 동의한 사람에게 바뀐 안내를 계정마다 한 번 보여 주고, "나중에"면 서버로 보내지 않아 이전 동의 범위로 이어 간다.
- 새 오류 코드: `AI_1312`(녹음이 너무 길어요, 422), `AI_1313`(녹음 정리 한도, 429), `AI_1314`(같은 요청 처리 중, 409), `AI_1315`(계획이 올바르지 않아요, 422), `AI_1316`(`Idempotency-Key` 없음, 400), `AI_1318`(같은 키로 다른 요청, 422), `TODO_0841`~`TODO_0846`(반복 할 일). 차감하지 않은 오류는 공개 상세에 `charged: false`를 싣는다.

## 배포 전 확인

- 운영 env에 AI 키 3개를 추가하고 `AI_PROVIDER_ORDER`는 평가 후 정한다. 키 값은 문서에 쓰지 않는다. Claude 키는 워크스페이스 키로 새로 발급받아야 한다.
- 위 마이그레이션 6개를 적용한다. `todo_series`는 기존 묶음을 규칙으로 이관한다.
- [심사 메모 초안](app-review-notes.ko.md)([영어](app-review-notes.en.md))에 데모 계정을 채워 스토어에 넣는다.
- 개인정보처리방침·약관의 위탁 업체 목록과 음성 처리 조항을 갱신한다(랜딩, 별도 저장소, 법무 검토 필요).
- 실기기 확인: iOS 온디바이스 인식 30분 연속 동작, Android 13 미만의 연속 인식·녹음 저장 제약.

## QA 기준 (결과는 측정 전)

- **화면**: 할 일 추가 시트(빈 상태·듣는 중·계획 중·실패·한도 도달), 긴 녹음(녹음·정리 중·결과·다시 듣기), 결과 화면, 메모 AI 검토, 결제 화면(무료·구독자), 한도 `PremiumDialog`, 기능 소개 시트, 코치마크, 알림 아이콘 3상태, 답글 접힘 전후.
- **글꼴·조합**: ko·en × 기본·large·xlarge × 라이트·다크. 최악 조합은 en × xlarge다. en은 ko의 1.4배 길이 안쪽이어야 한다.
- **기기**: iPhone 18 Pro(402×874pt), iPhone Duo, iPad, Android Pixel 9(412×915dp), Mac(레이아웃과 권한 문구만).
- **통과 조건**: 잘림이나 어색한 줄바꿈이 없다. 한국어가 단어 중간에서 끊기지 않는다(`hangul-word`). 버튼·칩·알약은 한 줄이다. 모션 줄이기가 동작한다. 가로·세로 모두 시트와 녹음 화면이 가려지지 않는다.
- **개인정보**: 분석 이벤트·Sentry·로그에 말한 내용, 전사 글자, 할 일 제목이 없다.
- **측정 전**: 음성 인식 정확도, 응답 지연, AI 정확도, 비용, 120fps 여부, 실기기 캡처 결과.
