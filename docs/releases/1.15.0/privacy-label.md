# 1.15.0 개인정보 라벨 변경 메모 (예정)

**상태: 초안.** 구현이 끝난 뒤 실제 데이터 흐름을 다시 확인하고 App Store Connect와 Play Console에 입력한다. 콘솔의 현재 값은 이 저장소에서 확인할 수 없으므로 "현재" 열은 1.14.0 심사 메모에 적힌 항목만 채웠다.

## 바뀌는 데이터 흐름

| 데이터                            | 1.14.x (현재)                                                                                      | 1.15.0 (예정)                                                                                                                  |
| --------------------------------- | -------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------ |
| 음성(오디오)                      | 할 일 추가 시트의 음성 버튼 하나(한 번 말한 내용을 글자로 바꿔 입력). 녹음 파일은 저장하지 않는다. | 녹음 파일은 기기에만 저장한다(30일 뒤 자동 정리, 설정에서 삭제 가능). 서버로 보내지 않는다.                                    |
| 사용자 콘텐츠 (할 일·메모 텍스트) | 서버 저장                                                                                          | 같은 저장에 더해, 음성 결과와 메모 글자를 AI 정리를 위해 Anthropic·Google·OpenAI에 보낸다. 서버는 전사 글자를 저장하지 않는다. |
| 위치·기기 식별자·진단             | 1.14.0 심사 메모 기준                                                                              | 변화 없음                                                                                                                      |

- 음성 인식은 기기 인식을 기본으로 하되, 기기 인식을 쓸 수 없으면 OS 네트워크 인식으로 떨어질 수 있다(아래 확인 필요 1).
- 서버 로그·Sentry·Analytics에는 말한 내용, 전사 글자, 할 일 제목을 남기지 않는다(분석 문서·공통 규칙).

| 항목                              | 예정 값                                                  | 근거                                                                                                                   |
| --------------------------------- | -------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------- |
| Audio Data                        | 수집 안 함                                               | 녹음 파일이 기기 밖으로 나가지 않는다. 확인 필요 1 참고.                                                               |
| User Content > Other User Content | 수집함, 사용자와 연결됨, 추적에 쓰지 않음, 목적: 앱 기능 | 할 일·메모 텍스트와 AI 정리용 글자를 서비스 제공자(AI 업체)가 처리한다. Apple 정의상 제3자 처리도 "수집"으로 신고한다. |
| Location                          | 1.14.0과 같음 (앱 기능, 추적 안 함)                      | 1.14.0 심사 메모                                                                                                       |

## 심사·동의 연결 (App Review)

- **AI 제3자 전송 동의**: 1.15 앱은 새 동의 화면을 한 번 띄운다. 세 업체 이름과 "글자만 보낸다", "녹음은 기기에만 있다"를 쓴다. 기존 동의 사용자는 Google만 쓰고 기능은 그대로 동작한다.
- **권한 문구(ko·en)**: 마이크와 음성 인식 사유에 "녹음은 기기에만 저장돼요"를 넣는다(`app.config.ts` 플러그인과 native-locales). 심사 메모에 마이크·음성 인식이 왜 필요한지 쓴다.
- **심사 메모**: 1.14.0 메모 구조를 따라 "1.15.0에서 바뀐 것"과 "테스트 방법"을 추가한다.
- **개인정보처리방침·이용약관**: 위탁 업체 목록과 음성 처리 조항을 갱신한다(랜딩 별도 저장소, 법무 검토).

## 확인 필요 (사용자 결정 또는 콘솔 확인)

1. **OS 음성 인식 경로**: 기기 인식이 안 되면 iOS·Android의 음성 인식 서비스가 음성을 처리할 수 있다. 개발자가 받는 데이터는 아니지만, 라벨을 "수집 안 함"으로 신고하기 전에 실제 인식 경로와 각 OS의 정책 문구를 확인한다. 긴 녹음은 기본적으로 기기 인식(`requiresOnDeviceRecognition`)을 쓰므로 영향이 작다.
2. **Play의 AI 업체 분류**: 서비스 제공자인지 제3자 공유인지 Play 정책 기준으로 확정한다.
3. **AI 업체 보관·학습 정책**: 각 업체의 API 데이터 보관 기간과 학습 사용 여부는 측정하거나 확인하지 않았다. 처리방침에 쓰기 전에 각 업체의 현재 정책을 확인한다.
4. **App Review 5.1.2 계열 지침**: 제3자 AI에 개인 정보를 보내는 경우의 동의·고지 요건을 제출 전에 최신 가이드라인으로 다시 확인한다.
