# 1.15.0 개인정보 라벨 변경 메모

**상태: 코드 대조 완료, 콘솔 입력 전.** 아래 데이터 흐름은 1.15.0 코드와 맞췄다. 신고 값은 App Store Connect와 Play Console에 입력하기 전에 사용자가 정한다. 콘솔의 현재 값은 이 저장소에서 확인할 수 없으므로 "현재" 열은 1.14.0 심사 메모에 적힌 항목만 채웠다. 최종 신고 판단과 제출은 사용자가 한다.

## 바뀌는 데이터 흐름

| 데이터                                  | 1.14.x (현재)                                                                                      | 1.15.0                                                                                                          |
| --------------------------------------- | -------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------- |
| 음성 입력                               | 할 일 추가 시트의 음성 버튼 하나(한 번 말한 내용을 글자로 바꿔 입력). 녹음 파일은 저장하지 않는다. | 빠른 말하기·긴 녹음이 음성을 글자로 바꾼다. 음성 인식 경로는 아래 세 흐름으로 나뉜다.                           |
| 저장 녹음 파일                          | 없음                                                                                               | 기기에만 저장한다(30일 뒤 자동 정리, 설정에서 삭제 가능). Aido 서버로 보내지 않는다.                            |
| 사용자 콘텐츠 (할 일·메모 텍스트, 글자) | 서버 저장                                                                                          | 글자를 Aido 서버로 보내고, AI 정리를 위해 Anthropic·Google·OpenAI에 보낸다. 서버는 전사 글자를 저장하지 않는다. |
| 위치·기기 식별자·진단                   | 1.14.0 심사 메모 기준                                                                              | 변화 없음                                                                                                       |

## 음성 인식 경로 (세 흐름을 따로 적는다)

1. **저장 녹음 파일**: 기기에만 있다. Aido 서버로 보내지 않는다. 이 사실만 "녹음 파일은 Aido 서버로 보내지 않아요"로 고지한다.
2. **음성 인식 경로**: 기기 인식(`supportsOnDeviceRecognition()`과 설치된 언어 확인)이 가능하면 기기에서 처리한다. 안 되면 네트워크 인식으로 넘어가며, 이때 음성이 Apple·Google 인식 서비스로 갈 수 있다. 어댑터가 이를 고르고(`requiresOnDeviceRecognition`이 조건부), 코드로 확인했다. 기기에서만 처리한다는 단정은 쓰지 않는다.
3. **글자**: 음성을 글자로 바꾼 뒤의 글자는 Aido 서버로 가고, AI 정리를 위해 AI 업체로 간다. 이것은 2번과 별개 항목이다.

- 서버 로그·Sentry·Analytics에는 말한 내용, 전사 글자, 할 일 제목을 남기지 않는다(분석 문서·공통 규칙).
- Analytics `voice_capture_started`의 `on_device`로 실제 기기 인식 비율을 본다.

## 심사·동의 연결 (App Review)

- **제3자 AI 전송 동의(5.1.2(i))**: 제3자 AI에 개인 정보를 보내려면 고지와 명시적 동의가 필요하다. 1.15 앱의 AI 동의 시트는 음성 인식 경로(기기 인식 우선, 안 되면 Apple·Google 네트워크 인식)와 AI 업체(글자만)를 따로 안내하고 명시적 동의를 받는다. 설정에서 철회할 수 있다(5.1.1). 이전 안내(2026-10-26)에 동의한 사용자에게는 바뀐 안내를 계정마다 한 번 보여 주고, 답하지 않으면 Google만 쓰며 기능은 그대로 동작한다.
  - **확인**: 이 요건은 가이드라인 원문이 아니라 요약으로 확인했다. 제출 전에 원문과 대조한다.
- **권한 문구(ko·en)**: 마이크와 음성 인식 사유에 Apple·Google 음성 인식 처리 가능성을 알리고, "녹음 파일은 Aido 서버로 보내지 않아요"를 쓴다. "폰에서만 처리"라는 단정은 쓰지 않는다(`app.config.ts` 플러그인과 native-locales).
- **심사 메모**: 1.14.0 메모 구조를 따라 "1.15.0에서 바뀐 것", 음성 인식 경로, "테스트 방법"을 추가한다.
- **개인정보처리방침·이용약관**: 위탁 업체 목록과 음성 처리 조항을 갱신한다(랜딩 별도 저장소, 법무 검토).
- **동의 거절**: 동의 시트의 "나중에"는 서버로 보내지 않는다. 설정에서 철회할 때만 `agreed:false`를 보낸다. "나중에" 뒤에는 AI를 다시 시도할 때 서버 `AI_1311`로 안내를 다시 띄운다.

## 사용자 확인 항목

1. **신고 판단**: 음성 인식 경로(Apple·Google)를 App Store Audio Data와 Play 음성 항목에 어떻게 신고할지 정한다. 위 표는 보수적인 안이다.
2. **App Store Audio Data**: Apple 인식 경로의 해석을 제출 전에 확인한다.
3. **Play의 AI 업체 분류**: 서비스 제공자인지 제3자 공유인지 Play 정책 기준으로 확정한다.
4. **5.1.2(i) 원문 대조**: 위 요약을 제출 전 원문과 맞춘다.
5. **AI 업체 보관·학습 정책**: 각 업체의 API 데이터 보관 기간과 학습 사용 여부는 측정하거나 확인하지 않았다. 처리방침에 쓰기 전에 각 업체의 현재 정책을 확인한다.
6. **제출**: 콘솔 양식 입력과 제출은 사용자가 한다.
