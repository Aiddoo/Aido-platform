# 1.14.1: 댓글 2단계 묶음·푸시 파이프라인·날씨 장면

기준: `main` 직행 PR #1196·#1201·#1198·#1199·#1202·#1203·#1205·#1206·#1207. 클라이언트는 [1.14.1 클라이언트](../../apps/mobile/docs/releases/1.14.1-client.md). 서버 변경 목록은 [CHANGELOG](../../apps/api/CHANGELOG.md).

## 요약

- 할 일 댓글을 댓글·답글 2단계 묶음으로 저장하고 `/v2` 읽기 API를 더한다. 1.14.0 이하 앱은 v1 응답 모양 그대로 2단계 값을 받는다.
- 푸시 발송을 Port–Adapter와 pg-boss 큐로 정리한다. 공급자 오류 분류, 실패 dead-letter, 리텐션 발송의 공용 outbox, 관리자 브로드캐스트 비동기 캠페인을 더한다.
- 푸시 data에 kind별 판별 유니온 `navigation`을 싣는다. 기존 필드는 구 앱용으로 유지한다.
- 날짜 계산을 공용 helper와 하나의 시간대 출처로 모으고, 직접 만든 집계·정렬·중복 제거를 es-toolkit으로 바꾼다.
- 소셜 로그인 응답에 `isNewUser`(선택 필드)를 더해 소셜 신규 가입을 GA `auth_signup`으로 구분한다.
- 앱: 할 일 상세 한 화면 댓글·답글, 더블탭 하트, 날씨 18가지 움직이는 장면과 해·달.
