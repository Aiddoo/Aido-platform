콕 답장·감사 기능이 서버 설정으로 꺼진 경우를 새 오류 코드 `NUDGE_1111`(404, "지금은 콕 답장과 감사를 사용할 수 없습니다.")로 알린다. 전에는 "없는 콕"과 같은 `NUDGE_1105`였다. 출시 앱(1.15.1 이하, `X-App-Version`이 없거나 1.15.2 미만)은 보낸 콕 목록이 `NUDGE_1105`로 꺼진 상태를 알아 같은 경우에 계속 `NUDGE_1105`를 받는다. "없는 콕·내 콕이 아님"은 모든 앱에 `NUDGE_1105` 그대로다. 답장·감사 API 5개의 404 문서에 `NUDGE_1111`을 더한다.
