구독·보상·역할이 바뀌는 순간 동시에 들어온 요청이 이전 권한과 프로필을 다시 캐시에 남겨 최대 10분 동안 바뀌기 전 상태가 보이던 경합을 막았다. 탈퇴 유예 중인 계정을 로그인으로 되살리면 권한도 바로 다시 읽어 프리미엄 사용자가 무료로 보이지 않는다. 한 사용자가 위치를 옮겨도 같은 격자의 다른 사용자가 쓰는 날씨 캐시를 지우지 않아 공급자를 다시 부르지 않는다. 운영자가 DB에서 ADMIN을 USER로 내리면 토큰을 갱신할 때 현재 역할로 발급해 갱신을 이어 가도 관리자로 남지 않는다(access token 수명 15분 안에 반영). 역할을 못 읽어도 갱신은 막지 않는다.
