# Native dependency patches

| Package                | Version   | Purpose                                                                                                                                                                                                                                                                                                                                                                                                   | Removal condition                                                                                                |
| ---------------------- | --------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------- |
| `@sentry/react-native` | `8.28.1`  | Expo Router 58 removed the private router store. Return the SDK's existing unsupported-router fallback directly so Metro does not resolve the missing optional import. Error capture, masked replay, and native SDK behavior remain unchanged.                                                                                                                                                            | Upstream removes the missing import or supports Expo Router 58 through compatible APIs.                          |
| `expo-widgets`         | `58.0.29` | The layout registry imports each widget's initial layout by absolute path. EAS local builds run from a macOS temp folder where `/var` and `/private/var` name the same files, so Metro rejected the import and `[CP-User] Build ExpoWidgets Bundle` failed the iOS archive. Resolve the layout file with `fs.realpathSync` before writing the import. Build script only; the widget runtime is unchanged. | Upstream resolves the real path. Recheck `eas build --local --platform ios --profile production` before removal. |

HeroUI Native 1.1.1 presents `BottomSheet` through the native `@lodev09/react-native-true-sheet` module, which needs no patch, so the former `@gorhom/bottom-sheet` Gesture Handler 3 patch was removed.

Sentry 8.28.1 is in the Expo SDK 58 recommended range (`~8.28.0`). It re-releases 8.28.0 with Cocoa SDK 9.29.3 signed by Sentry's new certificate ([sentry-cocoa#9645](https://github.com/getsentry/sentry-cocoa/issues/9645)). Sentry 8.29.0 still references the removed store. The app does not enable navigation tracing; this patch does not implement Expo Router automatic route attribution. Keep tracing disabled until an upstream-compatible integration is available. The patch touches the published JavaScript entry only and requires no native dependency change. References: [Expo bundled versions](https://github.com/expo/expo/blob/main/packages/expo/bundledNativeModules.json), [Sentry router helper](https://github.com/getsentry/sentry-react-native/blob/8.28.0/src/js/tracing/expoRouterStore.ts), [Sentry 8.29.0 release](https://github.com/getsentry/sentry-react-native/releases/tag/8.29.0).

`react-native-screens` 4.30.1 ships [#4990](https://github.com/software-mansion/react-native-screens/pull/4990) (the `NativeTabs` side rail on an iPhone Duo cold-launched unfolded), so the former backport patch was removed.

`react-native-keyboard-controller` 1.22.7 resolves Reanimated 4.7 animated refs in its own `safeScrollTo`, so the former 1.22.4 patch was removed.
