# Native dependency patches

| Package                | Version   | Purpose                                                                                                                                                                                                                                                                                                                                                                                                               | Removal condition                                                                                                                        |
| ---------------------- | --------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------- |
| `@sentry/react-native` | `8.28.0`  | Expo Router 58 removed the private router store. Return the SDK's existing unsupported-router fallback directly so Metro does not resolve the missing optional import. Error capture, masked replay, and native SDK behavior remain unchanged.                                                                                                                                                                        | Upstream removes the missing import or supports Expo Router 58 through compatible APIs.                                                  |
| `@gorhom/bottom-sheet` | `5.2.14`  | Existing gesture builders and relationships use Gesture Handler 3's `LegacyPanGesture`, `LegacySimultaneousGesture`, and `LegacyTextInput` exports consistently. `BottomSheetTextInput` also updates the keyboard `target` on the UI runtime: `.set(updater)` from JS reads and writes across threads, so a blur or focus landing next to a keyboard event dropped that event and left the sheet behind the keyboard. | Upstream supports Gesture Handler 3 or migrates the entire gesture relationship group, and updates the input `target` on the UI runtime. |
| `react-native-screens` | `4.30.1`  | Backport of [#4990](https://github.com/software-mansion/react-native-screens/pull/4990): size the tab bar controller's view to the host before attaching it. Without it, an iPhone Duo cold-launched unfolded shows no side-rail tab bar for `NativeTabs` ([#4989](https://github.com/software-mansion/react-native-screens/issues/4989)). iOS native source only.                                                    | Expo SDK 58 pins a `react-native-screens` release that includes #4990. Recheck an unfolded iPhone Duo cold launch before removal.        |
| `expo-widgets`         | `58.0.28` | The layout registry imports each widget's initial layout by absolute path. EAS local builds run from a macOS temp folder where `/var` and `/private/var` name the same files, so Metro rejected the import and `[CP-User] Build ExpoWidgets Bundle` failed the iOS archive. Resolve the layout file with `fs.realpathSync` before writing the import. Build script only; the widget runtime is unchanged.             | Upstream resolves the real path. Recheck `eas build --local --platform ios --profile production` before removal.                         |

The gesture patches cover source, compiled module/CommonJS entry points, and declarations. They do not change gesture behavior. These are compatibility adaptations rather than upstream support claims. HeroUI Native 1.0.11 declares Gesture Handler 3 as a supported peer and needs no override. Recheck drag gestures, nested scroll views, bottom-sheet inputs, and Android/iOS gestures when upgrading any of these dependencies.

References: [Gesture Handler 3 migration](https://docs.swmansion.com/react-native-gesture-handler/docs/guides/upgrading-to-3/).

Sentry 8.28.0 is the Expo SDK 58 recommended version. Sentry 8.29.0 still references the removed store. The app does not enable navigation tracing; this patch does not implement Expo Router automatic route attribution. Keep tracing disabled until an upstream-compatible integration is available. The patch touches the published JavaScript entry only and requires no native dependency change. References: [Expo bundled versions](https://github.com/expo/expo/blob/main/packages/expo/bundledNativeModules.json), [Sentry router helper](https://github.com/getsentry/sentry-react-native/blob/8.28.0/src/js/tracing/expoRouterStore.ts), [Sentry 8.29.0 release](https://github.com/getsentry/sentry-react-native/releases/tag/8.29.0).

`react-native-keyboard-controller` 1.22.7 resolves Reanimated 4.7 animated refs in its own `safeScrollTo`, so the former 1.22.4 patch was removed.
