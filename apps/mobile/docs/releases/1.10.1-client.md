# 1.10.1 클라이언트 변경 및 검증

기준은 develop의 1.10.0 소스다. 기능별 10개 브랜치를 develop 위에 쌓았으며 기존 Firebase 초기화 수정도 포함한다. 이 문서는 의사 코드 대신 해당 기준과 최종 구현의 실제 코드를 비교한다.

## 변경 목적

첫 홈 진입에서 선택적 날씨 요청이 라우터를 막지 않도록 하고, 위치 등록·캐시 갱신·예보 조회를 순서대로 처리한다. 날씨 헤더와 본문은 같은 시간·테마 팔레트를 사용한다. 친구와 메모의 빈 화면은 남은 화면 중앙을 사용하며, 캘린더 오류가 날짜 선택과 재시도를 가리지 않도록 한다. 서버 계약과 클라이언트 도메인을 분리하고 기존 입력 컴포넌트의 controlled Props를 유지한다.

할 일·메모·마이의 하단 아이콘은 체크리스트·종이와 연필·웃는 사람 실루엣으로 구분한다. 기존 여섯 고양이 키와 순서를 유지하면서 러시안 블루·크림·턱시도를 추가한다.

## 타입과 도메인 경계

API 입력·응답은 @aido/api 계약을 공유한다. 모바일 Service가 응답을 공유 Zod로 파싱하고 Mapper에서 클라이언트가 쓰는 평탄한 Domain 모양으로 변환한다. 날짜는 DTO ISO 문자열을 Domain Date로 한 번 변환한다. UI용 라벨과 색상은 presentations에서 만든다. 모델의 타입은 z.infer로 파생하고 Port나 UI의 원본 Props 확장까지 모델 스키마로 바꾸지는 않는다.

Policy는 도메인 객체와 외부 컨텍스트를 받는다. 원시값 계산을 조립하고 boolean, number 또는 도메인 식별자를 반환한다. 한국어 라벨·색상·JSX를 반환하지 않으며 this에 의존하지 않는다. 모든 타입이 컴파일된다는 사실과 실제 계약의 런타임 검증을 구분한다. 외부 SDK·기상청의 정상 응답까지 TypeScript만으로 보장할 수는 없다.

ORPC와 미디어 업로드는 추가하지 않았다. 기존 REST / Ky / 공유 Zod 경계를 사용한다.

## Provider 범위와 생명주기

AppProviders의 순서는 Gesture → Keyboard → FontScale → Language → Theme → HeroUI → Query → DI → LocalDate → Auth → RevenueCat → Notification → BottomSheet → QueryErrorBoundary → Overlay다. QueryClient와 DI Service 인스턴스는 기존 소유자가 유지한다. 인증된 (app) 영역에만 WeatherSessionProvider를 배치하고, Calendar는 FeedDate 아래의 feed 영역에 배치한다. 폼의 FormProvider는 각 페이지/단계에 둔다.

RootStack은 날씨 Promise나 날씨 Suspense를 기다리며 생성되지 않는 상태를 만들지 않는다. 선택적 기능의 실패는 가까운 경계에서 처리하고, 화면 이동·날짜 선택·탭 바는 유지한다. Expo Router의 ErrorBoundary는 error / retry를 사용하고 Query 경계는 QueryErrorResetBoundary와 연결한다.

## 날씨: 원인과 요청 순서

기존 배지가 사라지거나 현재 숫자가 비었던 조건은 위치 PUT 완료 이전의 예보 조회, 오래된 위치 캐시, 선택한 피드 날짜를 현재 날씨에 쓰는 흐름, 해당 시간의 예보가 없는 경우와 맞물린다. 현재 기온이 없는데 최저·최고 평균을 현재 값으로 만드는 처리는 제거했다. 재현 가능한 이 조건은 수정했지만 과거의 크래시 원인 전체를 로그 없이 단정하지 않는다.

1. 인증 영역에서 권한 상태를 확인한다. 홈과 라우터는 이미 렌더된다.
2. 안정된 홈에서 최초 설명을 한 번 보여준다. 사용자가 수락하면 OS 권한을 요청한다.
3. 허용된 권한으로 신선한 캐시 또는 제한된 위치 watch를 얻는다.
4. 역지오코딩의 국가와 좌표를 WeatherPolicy로 판정한다.
5. 진행 중 날씨 Query를 취소하고 위치 PUT을 await한다.
6. 기존 위치의 날씨 캐시를 제거하고 locationRevision을 증가시킨다.
7. 오늘의 한국 시각으로 예보·조건 Query를 조회한다. 선택한 캘린더 날짜와 분리한다.
8. 초기 로딩에는 고정 크기 Skeleton, 위치 없음에는 안내, 해외에는 국내 지원 안내, 예보 준비 중에는 다시 확인, 갱신 실패에는 마지막 데이터와 재시도를 표시한다.

Android 자동 watch는 mayShowUserSettingsDialog=false로 Google의 위치 정확도 설정 창을 자동으로 띄우지 않는다. 작은 GPS 오차는 자동 재등록을 생략하고 수동 새로고침은 위치를 다시 확인한다. 좌표 watch는 타임아웃/취소 때 remove하며 늦게 만들어진 구독도 즉시 해제한다. Promise 완료·실패·취소 경로에서 타이머와 abort listener를 정리한다. 배경에서는 위치 작업과 시계 타이머를 중단한다.

한국 국경 근처 해외 위치를 좌표만으로 지원 처리하지 않는다. KR 국가 코드와 예보 지원 범위를 함께 검사한다. 국가가 확인되지 않은 국내 좌표는 오류/재시도로 처리하며 해외 기온을 국내 예보처럼 표시하지 않는다.

헤더와 본문은 동일 팔레트를 사용한다. 단일 날씨 route는 Slot으로 렌더하고 부모 Stack.Screen에 custom header를 등록한다. useHeaderHeight와 safe-area를 사용한다. 실제 Android에서 재현한 ScreenStackFragment non-stack container 오류에 대해 Kotlin/Swift나 react-native-screens를 수정하지 않았다. 날씨 route 수정 후 Android와 iOS에서 진입/복귀를 각각 10회 검증했다. 추가 Release 테마 변경 검증에서 같은 upstream native toolbar 오류를 확보해, 나머지 12개 layout도 기존 공용 ScreenTitleBar.StackHeader로 연결한다. 제목/왼쪽/오른쪽 액션은 기존 Expo Router 옵션을 그대로 소비하고 Stack 전환은 유지한다. 생성된 native 코드나 SDK 패치 없이 custom header API를 사용한다. Android Release에서는 다크/라이트 설정 복귀와 메모/날씨 이동을 3회 반복했고 해당 native 오류는 0건이었다. iOS UIViewControllerBasedStatusBarAppearance는 Expo app.config.ts에서 true로 선언한다.

시간별 예보는 자정을 넘으면 dayOffset을 구분한다. 오늘 이미 지난 시간만 제외하고 다음 날 새벽은 유지한다. key는 dayOffset과 hour를 조합해 중복 시간을 구분한다. 4개 한국어 순수 view-model 테스트로 검증했다. 날씨 배지는 실패 때도 터치 가능한 자리를 유지한다.

NativeTabs가 자동 inset을 적용하는 첫 ScrollView가 친구 아바타의 가로 목록인 홈에서는 세로 컨테이너에도 contentInsetAdjustmentBehavior="automatic"을 명시한다. 수정 후 마지막 AI 카드가 탭 바에 가려지지 않고 올바른 route로 진입한다. 탭 바는 minimizeBehavior="never"로 항상 세 목적지를 보여준다. 프로필/약관 시트의 Content는 accessible={false}로 자식 컨트롤을 독립된 접근성 요소로 노출한다.

## Query / Router / 폼 책임

서버 상태는 TanStack Query, 입력과 시트의 세션 선택은 React/RHF, URL 상태는 Expo Router useLocalSearchParams가 담당한다. 라우트 파라미터는 라우트/해당 화면 훅 가까이서 Zod로 검증한다. Expo Router에는 TanStack Router의 loaderDeps를 이식하지 않는다. 존재하지 않는 useInfiniteQueries도 도입하지 않는다.

필수 데이터는 useSuspenseQuery / useSuspenseQueries와 가까운 Loading / Error를 사용한다. 선택적 날씨는 useQuery로 명시적 상태를 읽는다. 무한 목록은 useSuspenseInfiniteQuery를 사용하며 다음 페이지 실패를 첫 페이지 실패와 구분한다. 원본 Domain 캐시와 UI select를 분리해 같은 키에 다른 DTO/ViewModel 모양이 들어가지 않도록 한다.

useFriendById는 중복 React 상태나 별도 found/loading/error enum을 만들지 않는다. 동일 무한 캐시에서 친구 한 명을 select하고, 없는 동안 hasNextPage가 남아 있을 때 다음 페이지를 가져온다. isFetching 전체를 검사하고 cancelRefetch: false로 중복 페이지 요청과 백그라운드 갱신의 충돌을 피한다. 다음 페이지 오류는 재시도, 마지막 페이지까지 조회된 없음은 Redirect로 처리한다.

입력 래퍼는 원본 ComponentProps를 Omit해 바꾸는 부분만 재정의한다. PasswordInput은 Input의 value / onChange를 유지하고 secureTextEntry / rightContent만 소유한다. 약관 항목은 HeroUI의 isSelected / onSelectedChange를 유지한다. 이메일 도메인 제안도 value / onChange를 받으며 폼을 직접 구독하지 않는다. 부모 페이지가 회원가입/인증 폼을 소유하고 FormField와 useFormState/useWatch가 필요한 필드만 구독한다.

## 날짜와 공유 UI

표현은 locale/timeZone이 명확한 Intl 기반 공용 포맷을 사용한다. 날짜 계산과 캘린더 이동은 기존 dayjs 도구를 유지한다. 현재 Expo web 설정은 정적 export이며 요청별 SSR로 전환하지 않았다. 모델 렌더 중 숨은 new Date() 의존보다 외부 now를 받는 순수 함수와 시계 소유자를 사용한다.

레이아웃은 기존 Box / VStack / HStack / Grid / Result / StyledSafeAreaView를 재사용한다. 스켈레톤은 HeroUI Skeleton / SkeletonGroup을 사용한다. 빈 목록과 초기 오류는 Result로 남은 화면 중앙을 사용한다. 캘린더 오류는 날짜 조작 바로 아래의 작은 재시도 영역으로 처리한다. 하나의 세로 스크롤 소유자를 두며 NativeTabs가 처리하는 inset을 중복해서 더하지 않는다.

새 프로필 선택 시트는 9개 항목과 저장 버튼이 작은 화면에서도 닿도록 HeroUI Content에 고정된 높이와 @gorhom/bottom-sheet ScrollView를 사용한다.

## 앱 아이콘과 1.10.0 호환

모바일 package.json을 1.10.1로 올리고 app.config.ts는 이 값을 import한다. 루트/API의 독립적인 1.0.0 패키지 버전은 모바일 버전으로 강제 변경하지 않는다. 런타임은 fingerprint 정책을 유지한다. 아이콘 추가는 새 네이티브 빌드로 배포한다.

새 프로필 키는 DB에 원래 키로 저장한다. 1.10.1 이상 요청에는 새 키를 응답하고, 1.10.0·버전 헤더 없음·잘못된 버전에는 russian_blue → scottish_fold, cream_cat → white_cat, tuxedo_cat → black_cat으로 응답한다. 기존 URL과 null은 유지한다. auth/friend/nudge/cheer/comment의 명시적 DTO 경계에 적용하고 Vary 헤더에 X-App-Version을 포함한다.

앱과 서버를 함께 배포해도 이미 설치된 1.10.0 클라이언트가 즉시 바뀌지 않는다. 호환 API를 먼저 적용하고 새 앱을 제출해야 한다. 구버전 사용자 데이터 자체를 이전 키로 덮어쓰지 않는다. 지원 앱 버전은 서버 계약과 스토어 설치가 공존하는 동안 유지한다.

새 고양이 원본은 1024×1024 RGB PNG이며 외부 이미지 에셋을 가져오지 않고 새로 생성했다. 기존 여섯 키와 에셋을 보존한다. 원본 SVG에서 투명한 탭 PNG 24/48/72px를 생성해 두 플랫폼에서 동일한 형태를 사용하며 NativeTabs의 template tint로 테마와 선택 색상을 적용한다.

AppIconService는 한 번에 하나의 네이티브 변경만 수행하고 실제 네이티브 반환 키로 캐시를 갱신한다. Query 취소는 늦은 초기 조회가 선택을 덮어쓰지 않도록 한다. Mutation 오류는 화면에 마운트된 로컬 Dialog가 표시해 화면을 떠난 뒤 전역 오류 시트를 열지 않는다. Android의 기존 런처 재시작 안내는 유지한다.

 * | 플랫폼 | 동작 |
 * |--------|------|
 * | **iOS** | 아이콘이 즉시 변경된다 (런타임 핫스왑). |
 * | **Android** | `setIcon()` 호출 시 **앱이 종료(재시작)**된다. activity-alias 전환에 의한 OS 레벨 제약이다. |
 *
 * > Android 재시작 동작은 `expo-quick-actions`뿐 아니라 모든 동적 아이콘 라이브러리에 공통이다.
 * > 호출부에서 Android인 경우 사전 확인 Dialog를 표시하는 것을 권장한다.
 *
 * @returns currentIcon - 현재 활성 앱 아이콘 키
 * @returns isSupported - 디바이스의 동적 아이콘 변경 지원 여부
 * @returns isChanging - 아이콘 변경 진행 중 여부 (중복 호출 방지용)
 * @returns changeIcon - 아이콘 변경 함수. 동일 아이콘이거나 변경 중이면 무시된다.
 *
 * @see https://github.com/EvanBacon/expo-quick-actions
 *
 * @example
 * ```tsx
 * const { currentIcon, isSupported, isChanging, changeIcon } = useAppIcon();
 *
 * // Android에서는 재시작 경고 후 호출
 * if (Platform.OS === 'android') {
 *   showRestartDialog(() => changeIcon('black_cat'));
 * } else {
 *   changeIcon('black_cat');
 * }
 * ```
 */
export const useAppIcon = () => {
  const [currentIcon, setCurrentIcon] = useState<AppIconKey>('default');
  const [isChanging, setIsChanging] = useState(false);
  const isSupported = AppIcon.isSupported;

  useEffect(() => {
    if (!isSupported) return;

    AppIcon.getIcon?.().then((nativeValue) => {
      setCurrentIcon(resolveIconKey(nativeValue));
    });
  }, []);

  const changeIcon = useCallback(
    async (key: AppIconKey) => {
      if (key === currentIcon || isChanging) return;

      setIsChanging(true);

      try {
        await AppIcon.setIcon?.(toNativeIconName(key));
        setCurrentIcon(key);
      } finally {
        setIsChanging(false);
      }
    },
    [currentIcon, isChanging],
  );

  return { currentIcon, isSupported, isChanging, changeIcon };
};
````

import type { AppIconGateway } from '@src/core/ports/app-icon-gateway';

import { type AppIconKey, AppIconPolicy } from '../models/app-icon.model';

export class AppIconService {
  readonly #gateway: AppIconGateway;
  #pendingChange: Promise<AppIconKey> | null = null;

  constructor(gateway: AppIconGateway) {
    this.#gateway = gateway;
  }

  isSupported = (): boolean => this.#gateway.isSupported();

  getCurrentIcon = async (signal?: AbortSignal): Promise<AppIconKey> => {
    const nativeKey = await this.#gateway.getCurrentIcon();
    if (signal?.aborted) throw new Error('App icon lookup cancelled');
    return AppIconPolicy.resolveKey({ nativeKey });
  };

  changeIcon = (key: AppIconKey): Promise<AppIconKey> => {
    if (this.#pendingChange) return this.#pendingChange;

    const operation = this.#gateway
      .changeIcon(AppIconPolicy.nativeName({ key }))
      .then((nativeKey) => AppIconPolicy.resolveKey({ nativeKey }));
    const pendingChange = operation.finally(() => {
      if (this.#pendingChange === pendingChange) this.#pendingChange = null;
    });
    this.#pendingChange = pendingChange;
    return pendingChange;
  };
}

import { profileIconKeySchema } from '@aido/api';
import { z } from 'zod';

export const appIconKeySchema = profileIconKeySchema;
export type AppIconKey = z.infer<typeof appIconKeySchema>;
const nativeIconSchema = z.object({ nativeKey: z.string().nullable() });
type NativeIcon = z.infer<typeof nativeIconSchema>;
const selectedIconSchema = z.object({ key: appIconKeySchema });
type SelectedIcon = z.infer<typeof selectedIconSchema>;

export const AppIconPolicy = {
  resolveKey: (icon: NativeIcon): AppIconKey => {
    const result = appIconKeySchema.safeParse(icon.nativeKey);
    return result.success ? result.data : 'default';
  },
  nativeName: (icon: SelectedIcon): AppIconKey | null => (icon.key === 'default' ? null : icon.key),
} as const;

  Number.isFinite(latitude) &&
  Number.isFinite(longitude) &&
  latitude >= 33 &&
  latitude <= 39 &&
  longitude >= 124 &&
  longitude <= 132;

  latitude: number,
  longitude: number,

  previousLongitude: number,

import {

  useLocationGateway,

} from '@src/bootstrap/providers/di-context';
import {
  LocationUnavailableError,
  type LocationCoordinates,
} from '@src/core/ports/location-gateway';
import { WeatherPolicy } from '@src/features/weather/models/weather.model';
import { toError } from '@src/shared/errors';
import { isBusinessError, unwrap } from '@src/shared/errors/result';
import { useQueryClient } from '@tanstack/react-query';
import {
  createContext,
  type PropsWithChildren,
  use,
  useCallback,
  useEffect,
  useRef,
  useState,
} from 'react';
import { AppState } from 'react-native';

import { WEATHER_QUERY_KEYS } from '../constants/weather-query-keys.constant';
import { createWeatherClock } from '../view-models/weather-clock.view-model';

type LocationStatus =
  'checking' | 'registered' | 'unregistered' | 'denied' | 'unsupported' | 'error';
interface WeatherSession {
  clock: ReturnType<typeof createWeatherClock>;
  locationRevision: number;
  status: LocationStatus;
  isSyncing: boolean;
  needsIntroduction: boolean;
  locationName: string | null;
  syncLocation(requestPermission?: boolean): Promise<void>;
  dismissIntroduction(): void;
}
const WeatherSessionContext = createContext<WeatherSession | null>(null);

export function WeatherSessionProvider({ children }: PropsWithChildren) {
  const gateway = useLocationGateway();
  const errorReporter = useErrorReporter();
  const locationState = useWeatherLocationStateService();
  const service = useWeatherService();
  const queryClient = useQueryClient();
  const [clock, setClock] = useState(() => createWeatherClock(new Date()));
  const [locationRevision, setLocationRevision] = useState(0);
  const [status, setStatus] = useState<LocationStatus>('checking');
  const [isSyncing, setIsSyncing] = useState(false);
  const [needsIntroduction, setNeedsIntroduction] = useState(true);
  const [locationName, setLocationName] = useState<string | null>(null);
  const mounted = useRef(false);
  const activeRequest = useRef<Promise<void> | null>(null);
  const abortController = useRef<AbortController | null>(null);
  const previousCoordinates = useRef<LocationCoordinates | null>(null);
  const lastSynchronizedAt = useRef(0);

  const dismissIntroduction = useCallback(() => {
    setNeedsIntroduction(false);
    try {
      locationState.markIntroductionSeen();
    } catch {
      /* 이번 세션의 안내 종료는 유지한다. */
    }
  }, [locationState]);

  const syncLocation = useCallback(
    (requestPermission = false): Promise<void> => {
      if (!mounted.current) return Promise.resolve();
      if (activeRequest.current) return activeRequest.current;
      const controller = new AbortController();
      abortController.current = controller;
      const task = async () => {
        try {
          let permission = await gateway.getPermission();
          if (controller.signal.aborted) return;
          if (!permission.granted && requestPermission && permission.canAskAgain) {
            dismissIntroduction();
            permission = await gateway.requestPermission();
            if (controller.signal.aborted) return;
          }
          if (!permission.granted) {
            setStatus(permission.canAskAgain ? 'unregistered' : 'denied');
            setNeedsIntroduction(permission.canAskAgain && !locationState.hasSeenIntroduction());
            return;
          }
          setNeedsIntroduction(false);
          setIsSyncing(true);
          const coordinates = await gateway.getCoordinates(controller.signal);
          const place = await gateway.getPlace(coordinates, controller.signal);
          if (controller.signal.aborted) return;
          if (
            !WeatherPolicy.isSupportedLocation({ ...coordinates, countryCode: place.countryCode })
          ) {
            setStatus(
              place.countryCode === null && WeatherPolicy.isWithinSupportedBounds(coordinates)
                ? 'error'
                : 'unsupported',
            );
            setLocationName(null);
            return;
          }
          if (
            !requestPermission &&
            previousCoordinates.current &&
            !WeatherPolicy.isRelocationNeeded(coordinates, previousCoordinates.current)
          ) {
            setStatus('registered');
            lastSynchronizedAt.current = Date.now();
            return;
          }
          await queryClient.cancelQueries({ queryKey: WEATHER_QUERY_KEYS.all });
          unwrap(await service.updateLocation(coordinates, controller.signal));
          if (controller.signal.aborted) return;
          queryClient.removeQueries({ queryKey: WEATHER_QUERY_KEYS.all });
          previousCoordinates.current = coordinates;
          setLocationName(place.name);
          setLocationRevision((value) => value + 1);
          setStatus('registered');
          lastSynchronizedAt.current = Date.now();
        } catch (error) {
          if (!controller.signal.aborted) {
            if (!(error instanceof LocationUnavailableError) && !isBusinessError(error)) {
              try {
                errorReporter.captureException(toError(error), { feature: 'weather_location' });
              } catch {}
            }
            setStatus((current) => (current === 'unsupported' ? current : 'error'));
            setNeedsIntroduction(false);
          }
        } finally {
          if (mounted.current) setIsSyncing(false);
        }
      };
      const promise = task().finally(() => {
        if (activeRequest.current === promise) activeRequest.current = null;
        if (mounted.current && controller.signal.aborted && AppState.currentState === 'active')
          void syncLocation();
      });
      activeRequest.current = promise;
      return promise;
    },
    [dismissIntroduction, errorReporter, gateway, locationState, queryClient, service],
  );

  useEffect(() => {
    mounted.current = true;
    void syncLocation();
    let clockTimer: ReturnType<typeof setTimeout> | undefined;
    const reconcileClock = () => {
      clearTimeout(clockTimer);
      setClock(createWeatherClock(new Date()));
      if (AppState.currentState === 'active')
        clockTimer = setTimeout(reconcileClock, 60_000 - (Date.now() % 60_000) + 100);
    };
    reconcileClock();
    const subscription = AppState.addEventListener('change', (state) => {
      reconcileClock();
      if (state === 'active' && Date.now() - lastSynchronizedAt.current >= 30 * 60_000)
        void syncLocation();
      if (state === 'background') abortController.current?.abort();
    });
    return () => {
      mounted.current = false;
      clearTimeout(clockTimer);
      abortController.current?.abort();
      subscription.remove();
    };
  }, [syncLocation]);

  return (
    <WeatherSessionContext.Provider
      value={{
        clock,
        locationRevision,
        status,
        isSyncing,
        needsIntroduction,
        locationName,
        syncLocation,
        dismissIntroduction,
      }}
    >
      {children}
    </WeatherSessionContext.Provider>
  );
}

export function useWeatherSession(): WeatherSession {
  const context = use(WeatherSessionContext);
  if (!context) throw new Error('useWeatherSession must be used within WeatherSessionProvider');
  return context;
}

function DailyForecastSection({ items }: { items: DailyForecast[] }) {
  const palette = useTimePalette();
  const { t } = useTranslation('weather');

  const globalMin = Math.min(...items.map((i) => i.temperatureMin));
  const globalMax = Math.max(...items.map((i) => i.temperatureMax));
  const range = globalMax - globalMin || 1;

  return (
    <VStack
      mx={20}
      py={16}
      px={16}
      gap={8}
      mb={12}
      className="rounded-2xl overflow-hidden"
      style={{ backgroundColor: palette.glassCard }}
    >
      <Text size="b3" weight="semibold" className="mb-1" style={{ color: palette.text }}>
        {t('screen.weekly')}
      </Text>
      {items.map((item) => {
        const Icon =
          resolveIconByPrecipitation(item.precipitationType) ?? resolveIconBySky(item.skyCondition);
        const iconColor =
          item.precipitationType === 'NONE'
            ? resolveSkyIconColor(item.skyCondition, palette.icon)
            : palette.icon;
        const dayLabel = formatDayLabel(item.date);
        const barLeft = ((item.temperatureMin - globalMin) / range) * 100;
        const barRight = ((globalMax - item.temperatureMax) / range) * 100;

        return (
          <HStack key={item.date} align="center" className="py-1 gap-3 px-1">
            <Text size="b3" weight="medium" className="w-8" style={{ color: palette.textSub }}>
              {dayLabel}
            </Text>

            <VStack align="center" className="w-10">
              <Icon width={20} height={20} color={iconColor} />
              {item.precipitationProbability > 0 && (
                <Text size="e2" style={{ color: palette.accent }}>
                  {item.precipitationProbability}%
                </Text>
              )}
            </VStack>

            <Text size="b3" weight="medium" className="w-8 text-right" style={{ color: '#A0D8FF' }}>
              {Math.round(item.temperatureMin)}°
            </Text>
            <View
              className="flex-1 h-1 rounded-full overflow-hidden"
              style={{ backgroundColor: palette.glass }}
            >
              <View
                className="absolute h-1 rounded-full overflow-hidden"
                style={{ left: `${barLeft}%`, right: `${barRight}%` }}
              >
                <Svg width="100%" height={4}>
                  <Defs>
                    <SvgLinearGradient id={`tempBar-${item.date}`} x1="0" y1="0" x2="1" y2="0">
                      <Stop offset="0" stopColor={getTempColor(item.temperatureMin)} />

            <Text size="b3" weight="medium" className="w-8" style={{ color: palette.text }}>
              {Math.round(item.temperatureMax)}°
            </Text>
          </HStack>
        );
      })}
    </VStack>
  );
}

function getDustGrade(value: number, type: 'pm10' | 'pm25'): string {
  const thresholds = type === 'pm10' ? ([30, 80, 150] as const) : ([15, 35, 75] as const);
  if (value <= thresholds[0]) return globalT('weather:dust.good');
  if (value <= thresholds[1]) return globalT('weather:dust.normal');
  if (value <= thresholds[2]) return globalT('weather:dust.bad');
  return globalT('weather:dust.veryBad');
}

function getTempColor(temp: number): string {
  if (temp >= 35) return '#FF3B30';
  if (temp >= 30) return '#FF8A80';
  if (temp >= 25) return '#FF9500';
  if (temp >= 20) return '#F5C842';
  if (temp >= 15) return '#8BC34A';
  if (temp >= 10) return '#4FC3F7';
  if (temp >= 5) return '#A0D8FF';
  return '#2196F3';
}

function formatDayLabel(dateStr: string): string {
  const day = new Date(`${dateStr}T00:00:00Z`).getUTCDay();
  return getWeekdayLabels()[day] ?? '';
}

## Stack PR과 CI

10개 PR의 base를 develop → 이전 스택 순서로 연결한다. stack:1.10.1 라벨을 모두 붙이고 ci:stack-tip은 마지막 PR에만 붙인다. 중간 또는 draft PR은 비싼 검증 작업을 runner 할당 전에 제외한다. 최종 PR은 자신의 작은 차이만 검사하지 않고 pinned develop base SHA부터 tip SHA까지 누적 변경을 검사한다. 메타데이터 변경 중 잘못된 tip·분기·누락·cycle은 gate에서 거절한다.

관련 없는 라벨이나 본문 수정은 검증을 재시작/취소하지 않는다. 모든 코드·native QA 수정을 끝낸 뒤 마지막 PR을 ready로 전환해 중복 CI 비용을 피한다. 검증이 성공하면 사용자 승인 범위에 따라 gh stack merge로 develop에 머지한 뒤 develop → main 릴리스 PR과 기존 서버 배포를 진행한다. 로컬 production AAB/IPA를 바탕화면에 생성한다. 스토어 제출은 별도로 요청되지 않았다.
