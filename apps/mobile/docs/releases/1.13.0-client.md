# 1.13.0 클라이언트: 친구 초대 링크·보상, 결제 정합성, 날짜·위젯, 의존성·보안 정비

추적 이슈: #443 · 기준: `develop` (**작성 예정**: 릴리스 PR 기준 커밋)

## 무엇을 바꿨나

- 친구를 초대 링크(`https://aido.kr/i/{code}`)로 데려올 수 있어요. 초대받은 사람은 수락하면 바로 친구가 되고 프리미엄 7일을 받아요(기기·계정당 한 번). 초대한 사람은 친구가 가입하고 14일 안에 할 일을 끝낸 날이 이틀이 되면 프리미엄 7일과 친구 자리 1개를 받아요.
- 카카오톡으로 초대 링크를 공유해요. ‘발자국 모으기’에서 초대 현황을 보여 줘요.
- 구독 중에 받은 보상 기간은 구독이 끝난 뒤 이어서 시작해요. 구독 화면에 보상 기간을 보여 줘요.
- 자정이 지나면 위젯이 새 날짜의 할 일을 보여 줘요. 언어와 시간대 변경은 앱을 다시 켜지 않아도 반영돼요.
- 서버 의존성과 env 설정을 정리하고, 취약점 점검을 CI에 넣었어요.
- 3·5·10 단계 보상은 이번 버전에 넣지 않았어요. 데이터 구조만 준비했어요.

로그인 토큰·저장 키, 기존 DTO, 푸시 payload, 위젯 URI, OAuth 주소(`{scheme}://auth/{provider}`)는 바꾸지 않았어요. 새 필드는 모두 선택 항목으로 추가해서 구버전 앱에서도 동작해요. **작성 예정** (구버전 1.12.1 호환 확인)

## 읽은 자료와 버린 대안

- 초대 링크 웹 경로 `aido.kr/i/{code}`는 랜딩의 `proxy.ts` rewrite와 `.well-known`(AASA, assetlinks) 설정을 따랐어요. **작성 예정**
- 초대 링크는 HTTPS 앱 링크(`https://aido.kr/i/{code}`, iOS `associatedDomains`, Android `autoVerify`)와 기존 `aido://invite/{code}` 두 경로로 열어요.
- 프리미엄 지급은 RevenueCat을 호출하지 않고 서버가 직접 관리해요. RevenueCat 리스너는 `/me` 캐시에 상태를 쓰지 않고 다시 불러오기만 해요.
- 카카오 공유는 `@react-native-kakao/share` 공식 SDK를 써요.
- 시트와 다이얼로그는 새로 만들지 않고 기존 `BottomSheet`, `usePremiumDialog`, `FeatureDiscoveryBottomSheet`를 재사용해요.
- ioredis 6과 React Native Firebase 27은 메이저 업그레이드라 별도 PR로 나눴어요.

## 구조 변경 요약

- **서버**: `social/invites` 모듈(초대 발급·수락·보상 지급), `billing`의 `PremiumGrant`와 `PremiumAccessPolicy`, `access`의 `ResourceBonus`(친구 자리), `/me` 응답에 `premiumSource`, `premiumEndsAt`, `willRenew` 추가.
- **모바일**: `features/invite/`를 새로 만들고, 날짜 기준은 `LocalDateProvider`(`useCalendars`)로 모았어요. 텔레메트리 키는 `shared/observability/telemetry-keys.ts` 한 파일에 모았어요.
- **정리**: "없음" 판단은 `== null`로 통일하고, zod `.check()`, es-toolkit `uniq`, ts-pattern `.exhaustive()`로 바꿨어요. `findOtherEntitlementExpiry`와 RevenueCat 리스너의 캐시 직접 쓰기를 지웠어요.

## 라이브러리

- 서버: zod 4.3.6 → 4.6.7, `@sentry/nestjs` 11.9, `@nestjs/swagger` 12.0.4, bullmq·ai·`@ai-sdk/google` 패치, pg-boss 12.38.
- 모바일: `react-native-firebase`(RNFB) 26.4.1, `npx expo install --check` 통과. **작성 예정**
- override: body-parser, multer, undici, fast-uri 보안 버전으로 고정. 이유는 PR 0 본문에 적어요.
- 위험 수용: node-forge는 패치가 없고 `@expo/cli` 빌드 도구에만 쓰여요. zod 3.25는 `@expo/cli` 안에 있어요.
- 올리지 않음: TypeScript 6(Nest CLI 제약), @types/node 24(런타임 24), Babel 7, Expo 고정 패키지.

### 한국어

- 초대 링크를 카카오톡이나 다른 앱으로 보낼 수 있어요. 가입한 지 7일 안의 친구는 수락하면 프리미엄 7일을 받아요.
- 친구가 가입하고 14일 안에 할 일을 끝낸 날이 이틀이 되면 나도 프리미엄 7일과 친구 자리 1개를 받아요.
- 받은 보상은 ‘발자국 모으기’와 구독 화면에서 확인할 수 있어요.
- 자정이 지나면 위젯이 바로 새 날짜로 바뀌고, 언어·시간대 변경도 바로 반영돼요.
- 고양이 프로필이 빈 원으로 보이던 문제와 위젯 날짜가 잘리던 문제를 고쳤어요.

### English

- Share invites on KakaoTalk and more. Friends who joined within 7 days get 7 days of Premium.
- You get 7 days and 1 friend slot when they finish to-dos on 2 separate days within 14 days of joining.
- Track rewards in “Collect paw prints” and Subscription.
- Widgets update at midnight. Language and time zone changes apply instantly.
- Fixed blank cat profiles and cut-off widget dates.

## 운영 확인 사항

- 운영 DB migration(`invite_foundation`)은 배포 전에 사용자가 승인해서 실행해요. 배포 시 `INVITE_ENABLED=false`로 먼저 올리고, `/health`와 로그를 확인한 뒤 플래그를 켜요.
- env 키 변경: `INVITE_ENABLED`, `INVITE_CLAIM_HASH_SECRET`, `APP_ENV`를 추가하고 `AI_DAILY_LIMIT`, `REVENUECAT_SECRET_API_KEY`를 지웠어요. 운영 `.env` 실제 값 반영은 사용자가 해요. **작성 예정** (키 목록 diff)
- Sentry `feature` 태그 값이 바뀌어요(`invite` 추가). 해당 값으로 거르는 대시보드를 확인해요. **작성 예정**
- 랜딩(`aido.kr/i/*`)과 `.well-known` 파일은 서버 배포 뒤, 앱 심사 전에 올라가야 해요. **작성 예정** (AASA 응답과 Content-Type 확인)
- 새 알림 종류(`INVITE_JOINED`, `INVITE_REWARDED`, `PREMIUM_GRANT_ENDING`)는 1.13.0 이상에서만 보여요.
- 기존 1.12.1 앱 사용자는 초대 링크를 웹에서 열고, 새 알림은 받지 않아요.
