# 1.14.1 클라이언트: 할 일 댓글 한 화면(댓글 + 답글 2단계), 더블탭 하트

기준: `feat/mobile-comment-thread-list`(base `feat/api-comment-v2-read`, `stack:1.14.1`). 서버는
v2 읽기 API(`/v2/todos/:todoId/comments`, `…/replies`)를 쓰고 쓰기·좋아요는 1.14.0 이하와 같은 v1이다.
설계 규칙은 [`.claude/todo-comments.md`](../../.claude/todo-comments.md).

## 요약

- 할 일 상세 한 화면에서 댓글과 답글을 모두 본다. 대화 화면으로 이동하지 않고, 답글은 그 자리에서 펼친다.
- 답글은 한 단계만 들여쓰고, 누구에게 단 답글인지는 `@이름`으로 본문과 한 문단에 보인다.
- 본문을 두 번 탭하면 하트가 터지며 좋아요가 된다. 길게 누르거나 `⋯`를 누르면 아이콘이 붙은 메뉴가 뜬다.
- 작성 바가 키보드를 UI 스레드에서 따라가고, 답글 달기를 누른 행이 작성 바 위로 올라온다.
- 알림은 할 일 상세를 그 댓글 위치(`?comment=`)로 연다. 예전 대화 링크는 같은 위치로 옮긴다.

## 사용자 동작 Before / After

| 영역           | Before (1.14.0)                               | After (1.14.1)                                                        |
| -------------- | --------------------------------------------- | --------------------------------------------------------------------- |
| 구조           | 댓글 개요 + 대화 화면, 깊이마다 30px 들여쓰기 | 한 화면, 댓글·답글 2단계, 답글 본문 폭이 모두 같음                    |
| 답글 보기      | 대화 화면으로 push                            | 대표 답글 1개 → "답글 N개 더 보기"(10개씩) → "답글 숨기기"            |
| 답글 달기      | 대화 화면에서 작성                            | 같은 화면 작성 바. "○○님에게 답글 남기는 중" + 대상 행이 작성 바 위로 |
| 좋아요         | 버튼, 성공 후 모든 댓글 페이지 다시 받음      | 버튼 또는 더블탭 하트, 그 댓글만 낙관적으로 갱신(연타는 순서대로)     |
| 메뉴           | 텍스트만, 남의 댓글 삭제만 확인               | 아이콘(수정·복사·삭제 / 복사·신고·차단), 삭제는 항상 확인             |
| 이름이 길 때   | 이름이 0글자까지 줄어 태그만 보이기도 함      | 이름(최소 4글자) → 태그 순으로 줄고 배지·시간·⋯는 그대로              |
| 삭제된 댓글    | 대화 화면에서만 확인                          | 답글이 남으면 "삭제된 댓글이에요" 묘비, 없으면 행이 사라짐            |
| 이미 지운 글   | 일반 오류 토스트                              | "이미 삭제된 댓글이에요" + 그 행을 바로 뺌                            |
| 너무 빨리 보냄 | 서버 오류 문구                                | "너무 빨리 보내고 있어요. 잠시 후 다시 시도해 주세요"                 |
| 알림 탭        | 개요 위에 대화 화면을 쌓음                    | 할 일 상세가 그 묶음으로 이동, 답글이면 펼쳐서 잠깐 강조              |
| 상대 시간      | 렌더 시각 기준(열어 둔 동안 고정)             | 분 단위로 갱신(`useMinuteNow`)                                        |
| 하트 아이콘    | 1.5px 외곽선                                  | 1.8px 외곽선·채움 한 쌍(댓글·응원·알림 공통)                          |

## 구조 변경 요약

- 추가: `TodoCommentThreadList`, `TodoCommentReplies`, `TodoCommentItem`, `TodoCommentRailRow`, `TodoCommentHeartBurst`,
  `TodoCommentComposerBar`, `useCommentDoubleTap`, `TodoCommentRevealProvider`, `TodoCommentExpansionProvider`,
  `todo-comment-composer.model.ts`, v2 threads·replies 무한 쿼리, `CoachmarkService`(feature-discovery, 재정렬 안내 키 유지).
- 제거: 대화·개요 목록, `TodoCommentMessage`, 화면 전이·표시 Provider, 연결선·대화 위치 계산, view-model, overview·conversation 쿼리와 키, 관련 테스트.
- `comments/[commentId].tsx`는 Redirect만 남는다. 신고 시트 route는 그대로다.
- `metro.config.js`가 `__tests__/` 폴더를 번들에서 뺀다.

## 분석 이벤트

`todo_comment_created { todo_id, is_reply, chain_size }`(`depth` 제거), `todo_comment_deleted { todo_id, is_reply }`,
`todo_comment_liked { …, via }`, 새 이벤트 `todo_comment_replies_expanded`, `todo_comment_reply_started`,
`todo_comment_hint_dismissed`. 배포 뒤 GA 맞춤 측정기준에 `is_reply`, `via`를 등록한다.

## 호환

- 1.14.0 이하 앱은 v1 개요·대화 API를 그대로 쓴다(서버가 2단계 값으로 내려 준다).
- 예전 대화 URL·알림(`/todo/42/comments/cm_1`)은 `/todo/42?comment=cm_1`로 열린다.
- 댓글 초안 키(`todo-comment:<todoId>:new|reply|edit:<id>`)와 재정렬 안내 MMKV 키는 바꾸지 않았다.
