# 1.15.0 클라이언트: 말로 할 일 만들기·말로 메모하기·반복 할 일·한도 안내

전체 릴리스는 [1.15.0](../../../../docs/releases/1.15.0/README.md), 이벤트는 [analytics 측정 계획](../analytics-measurement-plan.md)을 따른다. 이전 QA의 기준 코드는 `da9b73498`이고, 그 뒤 전체 정리가 더 들어가 실기기 회귀 확인이 남았다. 미룬 일은 [릴리스 문서](../../../../docs/releases/1.15.0/README.md#출시-후로-미룬-일)에 있다.

## 요약

- **말로 할 일 만들기**: 할 일 추가 시트의 마이크. 들은 글자를 `POST /v1/quick-plans`로 보내고 같은 시트에서 카드를 고른다. 90초가 되면 멈춰서 여기까지 정리와 말로 메모하기로 이어 가기를 고르게 한다.
- **말로 메모하기**: 메모 탭에서 시작해 녹음·정리·결과 화면으로 이어진다. 초안과 녹음은 기기에 두고(30일 뒤 자동 삭제, 마이 탭 > 녹음 저장 공간에서 녹음만 삭제. 메모에 속하지 않은 파일은 용량에 세지 않고 다음 실행 때 한 시간이 지났으면 지운다), 글자만 `POST /v1/voice-notes/digest`로 보낸다. 메모 탭은 최근 3개(`VOICE_NOTE_PREVIEW_COUNT`)만 보이고 넘치면 전체 보기로 FlashList 화면을 연다.
- **반복 할 일**: 안 함·매일·평일·매주·격주·매월, 기간과 계속 반복. 고치고 지울 때 범위를 묻고, 목록 행에 반복 주기를 보인다.
- **한도 안내**: 서버 스냅샷(`GET /v1/entitlements`) 기반 `useEntitlementGate` → `PremiumUpsellBottomSheet` 하나로 모은다(같은 기능은 하루 한 번만 시트, 그 뒤엔 토스트). 결제 화면은 구독자·페이월로 나눈다.
- **연간 2주 무료 체험**: 스토어가 자격이 있다고 할 때만(iOS `checkTrialOrIntroductoryPriceEligibility` ELIGIBLE, Android 기본 옵션의 `freePhase`) 연간 카드에 "2주 무료" 칩, 요금제 아래 `TrialTimeline`(오늘 → 끝나기 3일 전 알림 → 결제일·금액), 버튼 "2주 무료로 시작하기"와 바로 아래 "11월 23일부터 연 ₩29,900 · 언제든 해지할 수 있어요"를 보인다. 기간 문구는 스토어가 준 단위와 수(일·주·개월·년)를 그대로 쓰므로 이미 다른 기간으로 체험을 받은 사용자도 맞게 보인다. 가장 큰 가격은 실제 청구액 그대로다(App Store 3.1.2). 결제 전 날짜는 오늘 + 체험 기간(날짜 키. 개월·년 단위는 말일을 넘기면 그 달 끝)으로 만든 예상이고, 결제 뒤에는 `/me`의 `premiumIsTrial`·`premiumPeriodEndsAt`으로 "무료 체험 중" 영수증(체험 종료일·첫 결제일·금액·스토어에서 해지)과 끝나기 3일 전부터의 안내(D-3~오늘)를 보인다. 체험 끝 3일 전 푸시는 서버가 `SYSTEM_NOTICE`로 보내 앱에 새 타입이 없다.
- **페이월·결제 뒤**: 맨 위 AI 혜택 4장 넘기기(글자 없는 그림 + 앱 글자, 막혀서 들어온 기능의 장부터), 요금제 → 오늘 결제 금액 → 발자국 도장 체험 일정 + 체험 끝나기 전 알림 토글 → 무료·프리미엄 비교표(이름을 누르면 설명이 뜬다). 결제가 끝나면 방금 산 요금제로 시작 화면을 보인다. 상세: [결제 화면](#결제-화면).
- **마이 탭·설정 화면**: 자주 쓰는 순서로 묶고 행마다 현재 값(친구 수, 알림 켜짐·꺼짐, 테마·글꼴·언어, 요금제, 앱 아이콘)과 듀오톤 아이콘을 둔다. 상세: [마이 탭과 설정 화면](#마이-탭과-설정-화면).
- **떠 있는 시각**: 한국에서 만든 오전 10시는 미국에서도 오전 10시이고 알림도 현지 10시에 울린다. 시간 표시와 수정 기본값은 모델의 `Todo.localTime`만 쓴다([날짜 규칙](../../../../docs/conventions/dates.md#5-떠-있는-시각)).
- **기타**: 읽지 않은 알림이 있으면 종을 채우고 점을 단다. 답글을 펼친 묶음에 숨길 답글이 없으면 "답글 숨기기"를 보이지 않는다. 초대 코드 입력의 "복사한 코드 붙여넣기" 칩을 걷어냈다. 칸을 길게 눌러 기기 메뉴로 붙여 넣고, 칸이 찬 뒤에 붙여 넣어도 붙여 넣은 코드로 바뀐다.

## 떠 있는 시각

- `Todo.scheduledAtMs`를 지우고 `Todo.localTime`(`HH:mm`)을 둔다. 매퍼 `toTodo`가 서버 `scheduledLocalTime`을 옮긴다. 서버가 칸을 비워 둔 시간 행만 `scheduledTime`을 기기 시간대로 바꾼다.
- 목록·친구 화면(`formatTodoTime`), 수정·날짜·시간 시트(`toTodoEditFormValues`), 만들 때의 낙관적 행, 날씨 옮기기 되돌리기가 같은 값을 쓴다. 날씨 브리핑은 예보와 맞출 순간을 날짜 + 벽시계 + 기기 시간대로 만든다. 서버가 재계산하기 전에도 현지 시각으로 맞는다.
- 저장 캐시의 모델 모양이 바뀌어 `QUERY_CACHE_SCHEMA_VERSION`을 3으로 올렸다. 이후 `User.createdAt` 모양(4)과 `Date`를 `Instant`로 바꾼 일(5)로 5까지 올렸다. 첫 실행에 이전 캐시를 버리고 다시 조회한다.
- 위젯 스냅샷에는 시각이 없어 바뀌지 않는다. 그대로인 것: "오늘"은 기기 시간대다.
- **시간대 보고**: 앱 시작, 복귀, 푸시 탭, 앞에 떠 있는 동안의 시간대 변경에 푸시 기기 보고가 나간다. 권한·토큰이 같아도 시간대가 다르면 보낸다(`PushDeviceService.report`). 서버는 `X-Timezone`을 읽어 바로 저장하고 재계산을 예약한다. 새 엔드포인트는 없다. 앞에 뜬 기기의 마지막 요청이 기준이다.
- **안내**: 보고가 성공한 뒤 처음 알아챈 시간대 변경이면 토스트로 한 번 알린다(`useTimezoneChangeNotice`). 앞으로 31일 안에 울릴 시간 있는 할 일이 없거나, 이름만 바뀌었으면(서울 ↔ 도쿄. 서버에서는 사용자와 규칙의 시간대만 바뀌고 `scheduledTime`과 알림 예약은 그대로다) 띄우지 않는다. 첫 설치와 첫 저장에도 띄우지 않는다. 마지막 값은 `aido_device_timezone_v1`에 계정과 함께 저장하고 로그아웃·탈퇴 때 지운다. 토스트는 겹쳐 뜨므로 화면이 밀리지 않는다. 확인 창은 없다.
- **Analytics**: `device_timezone_changed{offset_bucket, notice_shown}`. 시간대 이름과 도시는 보내지 않는다.
- **설정 화면에 기준 시간대를 넣지 않았다**: 화면을 여는 순간 그 기기가 기준이 되므로 값이 언제나 기기 시간대와 같고, 고를 수 있는 값이 아니라 할 일이 없다. 사람이 읽는 이름도 Hermes에서 기기마다 달라 `Asia/Seoul` 같은 값이 그대로 보일 수 있다.
- **한계**: 앱을 열기 전까지 알림은 옛 시간대로 울린다. 백그라운드 보고(`expo-background-task`)는 실행 시점이 OS 재량이고 강제 종료 뒤 돌지 않아 도착 직후를 풀지 못해 넣지 않았다. 기기 예약(로컬 알림)은 iOS 대기 64개 제한, 기기 여러 대 중복, 로그아웃·삭제 동기화 비용이 커서 고르지 않았다([이유](../../../api/docs/todo-floating-time.md#한계)).

**시간대를 바꿔 확인하기**: 할 일을 오전 10시로 만들고 기기 시간대를 뉴욕으로 바꾼 뒤 앱을 연다. 목록·수정 시트·친구 화면이 오전 10시인지, 1~2분 뒤 DB의 `scheduledTime`이 뉴욕 10시로 바뀌었는지, `pgboss.job`의 `todo-reminder.v1` 시작 시각이 현지 9시·9시 50분인지 본다. 서울로 되돌려 처음 값으로 돌아오는지 본다. 뉴욕으로 바꿔 앱으로 돌아왔을 때 토스트가 한 번 뜨는지, 할 일 없는 계정에서는 뜨지 않는지, 요청 없는 설정 화면에서 복귀해도 저장 시간대가 바뀌는지 본다. 5분 뒤로 시간을 몇 번 고쳐도 알림이 오지 않는지 본다.

## 시작 순서

말로 할 일 만들기와 말로 메모하기는 같은 순서로 시작한다: 한도 게이트 → AI 동의 → 마이크 권한 → 듣기.

| 동의 상태                    | 시작할 때                  | 이후                                                                               |
| ---------------------------- | -------------------------- | ---------------------------------------------------------------------------------- |
| 답한 적 없음                 | 시작할 때마다 안내         | "나중에"면 마이크 권한과 듣기로 가지 않고 그 자리에서 멈춘다. 입력 글자는 그대로다 |
| 이전 안내(2026-10-26)에 동의 | 바뀐 안내를 계정마다 한 번 | "나중에"는 서버로 보내지 않고 이전 동의 범위(Google)로 이어 간다                   |
| 현재 안내에 동의             | 묻지 않음                  |                                                                                    |

동의 상태를 읽지 못하면 묻지 않고 서버 `AI_1311` 판단에 맡긴다. 동의 때문에 막히면 실패 원인 `consent-required`로 따로 보인다.

## 음성 인식과 권한

권한과 인식 경로는 고른 인식 언어마다 판단한다(`SpeechRecognizer.getPermission(mode, locale)`·`requestPermission(mode, locale)`).

- **기기 인식 판단**: `supportsOnDeviceRecognition()`이 참이고 `installedLocales`에 그 언어가 있을 때만 기기 인식이다. iOS는 SDK가 기기 기본 언어만 확인해 주므로 기기 기본 언어와 같을 때만 기기 인식으로 본다. 확인되지 않은 언어는 네트워크 인식이다. iOS 빠른 말하기는 한국어 인식률이 더 좋아 언어와 상관없이 서버 인식을 쓰고(2026-11 실기기 비교), 말로 메모는 긴 녹음이라 기기 인식을 우선한다. 판단은 어댑터의 `getCapabilities(locale, mode)` 한 곳이고 `on_device`도 이 값을 쓴다.
- **iOS 권한**: 말로 메모하기가 기기 인식이면 마이크만 묻는다. 그 외(빠른 말하기, 받아쓰기, 네트워크 인식)는 마이크와 음성 인식을 묻는다.
- **언어 바꾸기**: 그 언어에 필요한 권한을 먼저 확인한다. 거절하면 듣던 언어로 이어 간다.
- **권한 안내**: 막은 권한(`PermissionSnapshot.missing`: 마이크, 음성 인식, 둘 다)에 맞는 문구와 설정 이동을 보인다.
- **인식 힌트(`speech-hints.ts`)**: iOS `contextualStrings`와 Android 13+ `EXTRA_BIASING_STRINGS`로 같은 옵션을 보낸다. 합쳐서 100개까지다. 카테고리·할 일 이름은 더 정확한 신호라 앞에 두고 기기 인식일 때만 넘긴다. 자주 틀리는 일반 단어(`COMMON_SPEECH_HINTS`, ko·en)는 개인 정보가 아니라 네트워크 인식에도 보낸다. 보정 신호일 뿐 보장은 아니다. 인식 뒤의 문맥 교정은 서버 프롬프트가 맡는다([AI 문서](../../../api/docs/ai.md#프롬프트-구성)).
- **고지**: 동의 시트는 "입력하거나 말한 내용"과 "음성은 Apple·Google 음성 인식이 글자로 바꿀 수 있어요"로 쓴다. 녹음 파일은 "이 기기에만" 대신 "아이두 서버로 보내지 않아요"로 쓴다. "폰에서만 처리"는 쓰지 않는다. 국외 이전(개인정보 보호법 제28조의8)은 동의할 때 알리도록 받는 곳에 "(미국)"을, 쓰는 곳에 "AI 학습·광고에는 쓰지 않고, 업체는 최대 30일 안에 지워요"를 적고, 개인정보처리방침 링크는 국외 이전 조항(`/privacy#overseas-transfer`)으로 바로 연다.

## 듣기

- **소리 표현**: 빠른 말하기는 `VoiceVisual`(구 + 양쪽 막대, Skia `RuntimeEffect`)이고 말로 메모는 타임라인 파형이다. 높이를 고정해 자막이 밀리지 않는다. 음량은 shared value로 UI 스레드에서 그린다. 프레임이 30fps 아래로 2초 이어지면 가벼운 구로 바꾼다(`VOICE_FRAME_BUDGET`). 듣기를 멈추거나 모션 줄이기면 프레임 콜백을 끈다.
- **자동 마무리**: 음량만 보면 시끄러운 곳에서 끝나지 않는다. 음량이 커도 새 글자가 1.5초 없으면(`SPEECH_TEXT_GRACE_MS`) 말이 아닌 것으로 본다. 음량 이벤트가 300ms 끊겨도 소리 없음으로 본다. 일부 Android 인식기는 말이 끝나면 이벤트를 보내지 않는다.
- **인식기 멈춤**: Android는 첫 문장 뒤에 `no-match`도 `end`도 없이 멈출 수 있다. 말소리가 3초 들리는데 글자가 6초 없으면 다시 연다(`VOICE_STALL_RESTART`). 실기기 확인 대상이다.
- **멈추는 때**: 앱이 백그라운드로 가거나 알림을 눌러 다른 화면이 올라오면 듣기와 재생을 멈춘다. 가려진 화면이 살아 있어 마이크가 켜져 있던 문제다. 들은 글자는 두고 돌아오면 이어 듣는다. 듣기 중 앱 안 배너를 탭한 경로는 글자를 잃는다([미룬 일](../../../../docs/releases/1.15.0/README.md#출시-후로-미룬-일)).
- **자막 줄바꿈**: Android는 단어 단위 줄바꿈 prop이 없어 자막·요약·핵심 포인트를 `WordWrapText`로 그린다. iOS는 `lineBreakStrategyIOS="hangul-word"`다. 쓰는 기준은 [UI 규칙](../architecture/ui.md#레이아웃-시프트워터폴목록)에 있다.
- **자막 가림**: 스크롤 가장자리는 `ScreenScrollShadow`·`SheetScrollShadow`(`expo-linear-gradient`)로 흐린다.

## 다시 듣기

- `useVoiceNotePlayer`는 `expo-audio`의 `useAudioPlaylist`로 녹음 조각을 한 큐에 올린다. 조각 경계는 네이티브 큐가 넘겨 JS 이벤트를 놓쳐도 멈추지 않는다.
- 다른 조각으로 탐색하면 새 항목이 열린 뒤에 위치를 적용한다. 마지막 조각까지 들은 뒤에는 처음부터 다시 재생한다.
- 재생 위치 구독(`useVoiceNotePlayback`)을 플레이어 바와 지금 항목을 그리는 자리로 내려 결과 화면 전체가 다시 그려지지 않는다.
- 녹음 파형은 shared value로 UI 스레드에서 그려 음량 이벤트가 React 렌더를 일으키지 않는다.

## 실패와 복구

- **오프라인**: 계획·정리·저장 뮤테이션은 `networkMode: 'always'`다. 오프라인이면 기다리지 않고 바로 실패 안내로 가고 글자를 남긴다. 말로 메모 정리는 오프라인이 확실하면 요청을 보내지 않는다. `expo/fetch`의 연결 실패(`fetch failed: …`)는 `KyHttpClient`가 `NetworkError`로 바꾼다. 말로 메모 화면이 캐시 없이 오프라인이면 스피너 대신 안내와 닫기를 보이고(`VoiceNoteDigest.Offline`), 연결되면 조회가 이어진다.
- **앱 제한 시간**: 앱은 서버 체인 제한보다 길게 기다린다. 메모 나누기 앱 30초·서버 25초, 빠른 말하기 앱 30초·서버 24초, 말로 메모 정리 앱 60초·서버 45초다.
- **멈춘 뒤의 `client`**: Android 인식기는 `stop` 뒤에 마지막 결과 대신 `client`를 줄 수 있고 이어서 `end`가 온다. 앱이 멈춘 구간의 `client`는 실패가 아니라 정상 종료다(`VoiceCapturePolicy.isStopAcknowledgement`). `end`에서 듣던 글자까지 확정한다.
- **모델 받기 안내**: 거절하거나 시스템 창에서 취소했거나 받을 수 없으면 그 언어는 다시 묻지 않는다(사용자·언어별 `offlineModelPromptRepository`). 받기가 끝난 경우만 빼고 기억한다.
- **시작 신호 없음**: 인식 시작 신호가 `VOICE_PREPARING_TIMEOUT_MS`(10초) 안에 오지 않으면 글자를 든 채 실패 상태로 간다.
- **빠른 말하기**: 정리 중에 그만두면 요청을 끊고 들은 글자를 입력 칸의 글자 뒤에 합친다(`VoiceTranscriptPolicy.mergeHeardTextIntoTitle`). 실패 뒤 마이크를 다시 누르면 글자를 유지한 채 새로 듣는다. 입력 칸에 친 글자가 있으면 실패 때 들은 글자를 옮기지 않고 그렇게 안내한다.
- **멱등 키**: 정리(`digestRequest`)와 저장(할 일 추가·메모로 저장)의 키를 초안에 남긴다. 응답을 놓치거나 앱을 다시 켜고 눌러도 같은 키로 보낸다. 저장 표시는 mutation의 `onSuccess`에서 남겨 화면이 내려간 뒤에 온 응답도 반영한다.
- **들은 글이 길 때**: 실패 뒤 입력 칸에 `maxLength`를 걸면 Android가 들은 글의 뒤를 지운다. 200자를 넘어도 글은 두고 저장할 때 줄이라고 알린다. 칸은 몇 줄까지 자란다.
- **실패 원인**: `consent-required` 외에 `memo-limit`(`MEMO_2003`)은 메모를 정리하라고 안내하고, `too-long`(`AI_1312`)은 이유를 알리고 다시 정리를 숨긴다.

## AI 표시

규칙은 [UI 규칙](../design.md#한도프리미엄ai-안내)에 있다.

- `AiFilledIcon`을 두는 곳: 할 일 추가 시트의 AI 줄, 말로 메모 정리 버튼 아래, 메모 ⋯ 메뉴의 AI로 할 일 나누기, AI 제안, 마이 탭 요약.

## 메모 화면

- **전환**: 메모 스택과 말로 남긴 메모는 같은 `slide_from_bottom`이다.
- **메뉴**: 머리글에는 고정·저장·⋯만 둔다. AI 나누기·바꾸기·삭제는 메뉴 글자로 옮겼다. iOS가 좁은 화면에서 툴바 버튼을 넘침 메뉴로 접으면 제목이 없어 아이콘만 보였기 때문이다. 접힌 스택은 `Stack.Toolbar.Menu`, 펼친 pane은 heroui `Menu` + `MenuActionItem`이고 항목과 순서가 같다.

서버가 회차를 앞으로 90일(`TODO_SERIES_LIMITS.VISIBLE_AHEAD_DAYS`)까지만 만들어, 달력 아래 한 곳에 "반복 할 일은 3개월 앞까지 보여요"를 보인다. 월 보기는 그 달이 일부라도 넘어가면, 주 보기는 고른 날이 넘어가면 보인다(`TodoRepeatPolicy.shouldShowRepeatHorizonHint`).

## 중요 표시

말로 메모하기의 깃발 버튼이다. 코드 이름(`isBookmarked`·`bookmark`)은 계약이라 그대로 두고, 화면 말은 "중요 표시 / Mark"로 쓴다.

- **어떤 문장인가**: 누른 시각에 말하던 문장, 말이 없으면 직전 문장, 아직 문장이 없으면 곧 나올 첫 문장이다(`getCaptionSentences`). 같은 문장을 여러 번 눌러도 하나다.
- **무엇을 하나**: 인식을 바꾸지 않는다. 정리할 때 표시한 문장을 핵심 포인트로 먼저 고른다(`voice-note-digest` 프롬프트).
- **안내**: 듣기가 시작되면 처음 한 번 말풍선이 뜬다(`voice-note-mark`). 바깥을 막지 않아 첫 탭이 안내를 닫으면서 바로 표시한다. 끝나면 라벨 옆 ⓘ로 같은 설명을 다시 본다.
- **개수**: 라벨에 "중요 표시 N"으로 보이고 정리·결과 화면과 같은 기준(표시한 문장 수)이다. 없으면 숨긴다. 표시가 있으면 깃발을 채우고 `main` 색으로 바꾼다.
- **조작 줄**: 세 칸의 폭을 같게 나누고(최대 360), 버튼 칸의 높이를 끝내기 버튼에 맞춰 버튼 중심과 라벨 기준선을 한 줄에 맞춘다.

## 안내 말풍선

코치마크와 ⓘ는 모두 `HintPopoverContent`(heroui-native `Popover`) 한 모양이다. 추가 시트의 첫 안내(`voice-quick-start`)가 남아 있으면 시트를 키보드 없이 열고, 바깥을 막지 않으며, 입력 칸이나 칩을 만지면 끝낸다. 투명한 바깥 레이어가 첫 탭을 삼켰고 접은 Duo에서는 말풍선이 키보드에 잘렸기 때문이다. 녹음·결과 첫 안내가 남아 있는 동안은 자막 아래와 첫 포인트 위를 비워 글을 가리지 않는다. 아이콘·제목·작은 X가 한 줄이고 그 아래에 설명이 온다. `CoachmarkPopover`는 대상 화면이 포커스를 얻고(`useIsFocused`) 자리가 잡힌 뒤(`useCoachmarkSettle` 450ms, 키보드가 움직이면 다시 기다린다)에만 열고, 그 전에는 소비하지 않는다. route 안에서만 쓴다. 내 정보를 읽기 전후로 대상을 다시 마운트하지 않는다. 추가 시트의 마이크 안내는 입력 칸을 덮지 않게 왼쪽으로 연다. 핵심 포인트의 시간 안내는 들을 녹음이 있을 때만 뜨고, 없으면 소비하지 않는다.

## 마이 탭과 설정 화면

- **마이 탭 순서**: 프로필 → 요금제 칸(`PlanSummary`: 무료면 이번 달 사용량 + 프리미엄 보기, 이용 중이면 영수증 규칙의 요약) → 초대 → 친구 → 기록 → 설정 → 구독 → 도움말 → 버전 → 계정. 메뉴 경로(pathname)는 그대로다.
- **현재 값**: 값만 그리는 컴포넌트가 기존 쿼리를 직접 읽고, 못 읽으면 값 없이 둔다(`FriendCountValue`, `PushStatusValue`, `PlanTypeValue`, `AppIconValue`, `LinkedAccountCountValue`). 새 쿼리 키는 없다.
- **설정 하위 화면**: 알림·테마·글꼴·언어·앱 아이콘·녹음 저장 공간·카테고리·차단 목록·내 정보를 `SettingsScreenLayout` + `SettingsListGroup`(행 `.Item`·`.Toggle`·`.Radio`, 듀오톤 `SettingsListGroup.Icon`) 한 틀로 맞췄다. 하나 고르기는 `SettingsListGroup.Radio` 하나다(문의·신고·날씨 옮기기 포함).
- **글꼴 크기**: 고르는 즉시 앱 전체 글꼴이 바뀐다(미리 보기도 고른 크기로 다시 그려진다).

## 기기에서 확인할 것

- 페이월: 한/영, 글꼴 작게·아주 크게, 라이트·다크에서 혜택 장 높이·그림 가장자리, 넘기기 제스처와 점, 비교표 Popover가 줄을 밀지 않는지, 막힌 기능(AI 리포트 / 친구)으로 들어왔을 때 시작 장.
- 결제(TestFlight 샌드박스): 체험 시작 → 시작 화면 → 확인 → 영수증 "연간 구독", 반영이 늦을 때 토스트 한 번.
- 마이 탭: 무료·프리미엄 계정의 요금제 칸, 값(알림 켜짐·꺼짐이 기기 권한을 바꾸고 돌아왔을 때 맞는지), 넓은 화면에서 메뉴 선택 표시.
- 글꼴 크기 화면: 고르는 즉시 앱 글꼴이 바뀌는지, 아주 크게에서 행이 잘리지 않는지.

## 코드 정리 결과

- **포트 이름**: 앱의 말로 바꿨다. `SyncStorage`는 `get`·`remove`·`keys`·`clear`, `ClipboardGateway`는 `copy`, `LocationGateway`는 `isGranted`, `PurchasesGateway`는 `purchase`·`restore`·`getOffering`·`getStatus`·`subscribe`·`setAnalyticsId`다.
- **함수 이름**: `xxxOf`를 `get`·`create`·`to`로 바꿨다.
- **플랫폼 분기**: `process.env.EXPO_OS`를 `Platform.OS`로 통일했다.
- **SDK import**: `shared/infra` 밖의 import를 `check:conventions`가 예외 없이 막는다.
- **문구 파일**: `voicePlan.json`을 `voice-plan.json`으로 바꿨다. namespace는 `voicePlan` 그대로다.
- **현재 시각**: 앱 모델의 순간은 `Instant`다. `useMinuteNow`와 날씨 모델의 `now`도 `Instant`이고 지금 순간은 `getNowInstant()`로 만든다. 영속 캐시의 `$date` 직렬화를 지웠다. `Date`는 네이티브 피커, 달력, 파일 수정 시각 경계에만 남는다.
- **함수 선언**: 모듈 수준 화살표 243개를 `function` 선언으로 바꿨다. 허용 목록은 비었다.
- **route 훅 이름**: 값이 하나면 `useXParam`, 여럿이면 `useXParams`다. `ScreenParams`·`RouteParams`는 `Params`로 줄였고 스키마는 `{name}ParamsSchema`다.
- **worklet 기본값**: `'worklet'` 함수의 매개변수 기본값은 UI 스레드에서 모듈 값을 못 찾아 죽는다(말로 메모 파형). `check:conventions`가 막는다.
- **푸시 기기 해제**: 진행 중인 보고를 기다리는 사이 세션이 끝나고 다시 로그인하면 해제를 보내지 않는다(세션 세대 비교). 새 세션의 기기 등록이 풀리던 경합을 막는다. 푸시 계약과 토큰 키는 그대로다.

- 앱은 1.15 서버가 항상 싣는 값만 읽는다(옛 서버 대체 분기 없음). 모르는 반복 빈도 하나로 목록 전체가 실패하지 않는다. 앱 1.15.0 출시 뒤에는 서버를 1.15 이전으로 되돌리지 않는다.
