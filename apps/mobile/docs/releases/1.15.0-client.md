# 1.15.0 클라이언트: 말로 할 일 만들기·말로 메모하기·반복 할 일·한도 안내

전체 릴리스는 [1.15.0](../../../../docs/releases/1.15.0/README.md), 이벤트는 [analytics 측정 계획](../analytics-measurement-plan.md)을 따른다.

## 요약

- **말로 할 일 만들기**: 할 일 추가 시트의 마이크. 들은 글자를 `POST /v1/quick-plans`로 보내고 같은 시트에서 카드를 고른다. 90초가 되면 멈춰서 여기까지 정리와 말로 메모하기로 이어 가기를 고르게 한다.
- **말로 메모하기**: 메모 탭에서 시작해 녹음·정리·결과 화면으로 이어진다. 초안과 녹음은 기기에 두고(30일 뒤 정리, 설정에서 녹음만 지우기), 글자만 `POST /v1/voice-notes/digest`로 보낸다.
- **반복 할 일**: 안 함·매일·평일·매주·격주·매월, 기간과 계속 반복. 고치고 지울 때 범위를 묻고, 목록 행에 반복 주기를 보인다.
- **한도 안내**: 서버 스냅샷(`GET /v1/entitlements`) 기반 `useEntitlementGate` → `PremiumDialog` 하나로 모은다. 결제 화면은 구독자·페이월로 나눈다.
- **기타**: 읽지 않은 알림이 있으면 종을 채우고 점을 단다. 답글을 펼친 묶음에 숨길 답글이 없으면 "답글 숨기기"를 보이지 않는다.

## 시작 순서

말로 할 일 만들기와 말로 메모하기는 같은 순서로 시작한다: 한도 게이트 → AI 동의 → 마이크 권한 → 듣기.

| 동의 상태                    | 시작할 때                  | 이후                                                                               |
| ---------------------------- | -------------------------- | ---------------------------------------------------------------------------------- |
| 답한 적 없음                 | 시작할 때마다 안내         | "나중에"면 마이크 권한과 듣기로 가지 않고 그 자리에서 멈춘다. 입력 글자는 그대로다 |
| 이전 안내(2026-10-26)에 동의 | 바뀐 안내를 계정마다 한 번 | "나중에"는 서버로 보내지 않고 이전 동의 범위(Google)로 이어 간다                   |
| 현재 안내에 동의             | 묻지 않음                  |                                                                                    |

동의 상태를 읽지 못하면 묻지 않고 서버 `AI_1311` 판단에 맡긴다. 동의 때문에 막히면 실패 원인 `consent-required`로 따로 보인다.

## 음성 인식과 권한

권한과 인식 경로는 고른 인식 언어마다 판단한다(`SpeechRecognizer.getPermission(mode, locale)`·`requestPermission(mode, locale)`).

- **기기 인식 판단**: `supportsOnDeviceRecognition()`이 참이고 `installedLocales`에 그 언어가 있을 때만 기기 인식이다. iOS는 SDK가 기기 기본 언어만 확인해 주므로 기기 기본 언어와 같을 때만 기기 인식으로 본다. 확인되지 않은 언어는 네트워크 인식이다.
- **iOS 권한**: 빠른 말하기·말로 메모하기가 기기 인식이면 마이크만, 네트워크 인식이면 마이크와 음성 인식을 묻는다. 받아쓰기는 항상 둘 다 묻는다.
- **언어 바꾸기**: 그 언어에 필요한 권한을 먼저 확인한다. 거절하면 듣던 언어로 이어 간다.
- **고유명사 힌트**: 카테고리·할 일 이름(`contextualStrings`)은 기기 인식일 때만 넘긴다. 네트워크 인식에는 보내지 않는다.
- **고지**: 동의 시트와 설정은 "글자로 바꾼 내용"으로 쓰고, 기기에서 바로 인식할 수 없으면 Apple·Google 음성 인식이 처리할 수 있다고 따로 알린다. 녹음 파일은 "이 기기에만" 대신 "아이두 서버로 보내지 않아요"로 쓴다.

## 다시 듣기

- `useVoiceNotePlayer`는 `expo-audio`의 `useAudioPlaylist`로 녹음 조각을 한 큐에 올린다. 조각 경계는 네이티브 큐가 넘겨 JS 이벤트를 놓쳐도 멈추지 않는다.
- 다른 조각으로 탐색하면 새 항목이 열린 뒤에 위치를 적용한다. 마지막 조각까지 들은 뒤에는 처음부터 다시 재생한다.
- 재생 위치 구독(`useVoiceNotePlayback`)을 플레이어 바와 지금 항목을 그리는 자리로 내려 결과 화면 전체가 다시 그려지지 않는다.
- 녹음 파형은 shared value로 UI 스레드에서 그려 음량 이벤트가 React 렌더를 일으키지 않는다.

## 실패와 복구

- **오프라인**: 계획·정리·저장 뮤테이션은 `networkMode: 'always'`다. 오프라인이면 기다리지 않고 바로 실패 안내로 가고 글자를 남긴다. 말로 메모 정리는 오프라인이 확실하면 요청을 보내지 않는다. `expo/fetch`의 연결 실패(`fetch failed: …`)는 `KyHttpClient`가 `NetworkError`로 바꾼다.
- **멈춘 뒤의 `client`**: Android 인식기는 `stop` 뒤에 마지막 결과 대신 `client`를 줄 수 있고 이어서 `end`가 온다. 앱이 멈춘 구간의 `client`는 실패가 아니라 정상 종료다(`VoiceCapturePolicy.isStopAcknowledgement`). `end`에서 듣던 글자까지 확정한다.
- **모델 받기 안내**: 거절하면 그 언어는 다시 묻지 않는다(사용자·언어별 `offlineModelPromptRepository`).
- **시작 신호 없음**: 인식 시작 신호가 `VOICE_PREPARING_TIMEOUT_MS`(10초) 안에 오지 않으면 글자를 든 채 실패 상태로 간다.
- **빠른 말하기**: 정리 중에 그만두면 요청을 끊고 글자를 입력 칸으로 옮긴다. 실패 뒤 마이크를 다시 누르면 글자를 유지한 채 새로 듣는다.
- **멱등 키**: 정리(`digestRequest`)와 저장(할 일 추가·메모로 저장)의 키를 초안에 남긴다. 응답을 놓치거나 앱을 다시 켜고 눌러도 같은 키로 보낸다. 저장 표시는 mutation의 `onSuccess`에서 남겨 화면이 내려간 뒤에 온 응답도 반영한다.
- **실패 원인**: `consent-required` 외에 `memo-limit`(`MEMO_2003`)은 메모를 정리하라고 안내하고, `too-long`(`AI_1312`)은 이유를 알리고 다시 정리를 숨긴다.

## 범위 시트

- 할 일 수정 시트(`KeyboardBottomSheet`)는 날짜·반복 선택과 같은 `ModalBottomSheet`로 범위를 묻는다. 아래 폼이 그대로 있어 입력값이 남고, 뒤로 가면 닫힘이 끝난 뒤 입력 칸에 다시 포커스한다.
- 키보드를 쓰지 않는 시트(더보기·시간·카테고리)는 `TodoScopeStep`으로 쓰던 시트 안에서 묻는다.

## 3개월 안내

서버가 회차를 앞으로 90일(`TODO_SERIES_LIMITS.VISIBLE_AHEAD_DAYS`)까지만 만들어, 달력 아래 한 곳에 "반복 할 일은 3개월 앞까지 보여요"를 보인다. 월 보기는 그 달이 일부라도 넘어가면, 주 보기는 고른 날이 넘어가면 보인다(`TodoRepeatPolicy.shouldShowRepeatHorizonHint`).

줄은 반복 아이콘 + 문구 + ⓘ이고(`RepeatHintLine`), 누르면 제목 "3개월 뒤 할 일은 아직 안 보여요", 설명 "반복이 끝난 건 아니에요. 날짜가 가까워지면 자동으로 생겨요."를 연다. 앞으로 31일 안에 반복 회차가 있는 계정은 처음 한 번 자동으로 열린다(`repeat-horizon` 코치마크). 달력 넘기기를 막지 않게 바깥을 막지 않고, X·줄 누르기·날짜 이동으로 끝난다. 범위는 매일 03:10 KST 작업이 채운다.

## 중요 표시

말로 메모하기의 깃발 버튼이다. 코드 이름(`isBookmarked`·`bookmark`)은 계약이라 그대로 두고, 화면 말은 "중요 표시 / Mark"로 쓴다.

- **어떤 문장인가**: 누른 시각에 말하던 문장, 말이 없으면 직전 문장, 아직 문장이 없으면 곧 나올 첫 문장이다(`getCaptionSentences`). 같은 문장을 여러 번 눌러도 하나다.
- **무엇을 하나**: 인식을 바꾸지 않는다. 정리할 때 표시한 문장을 핵심 포인트로 먼저 고른다(`voice-note-digest` 프롬프트).
- **안내**: 듣기가 시작되면 처음 한 번 말풍선이 뜬다(`voice-note-mark`). 바깥을 막지 않아 첫 탭이 안내를 닫으면서 바로 표시한다. 끝나면 라벨 옆 ⓘ로 같은 설명을 다시 본다.
- **개수**: 라벨에 "중요 표시 N"으로 보이고 정리·결과 화면과 같은 기준(표시한 문장 수)이다. 없으면 숨긴다. 표시가 있으면 깃발을 채우고 `main` 색으로 바꾼다.
- **조작 줄**: 세 칸의 폭을 같게 나누고(최대 360), 버튼 칸의 높이를 끝내기 버튼에 맞춰 버튼 중심과 라벨 기준선을 한 줄에 맞춘다.

## 안내 말풍선

코치마크와 ⓘ는 모두 `HintPopoverContent`(heroui-native `Popover`) 한 모양이다. 아이콘·제목·작은 X가 한 줄이고 그 아래에 설명이 온다. `CoachmarkPopover`는 대상 화면이 포커스를 얻고(`useIsFocused`) 자리가 잡힌 뒤(`useCoachmarkSettle` 450ms, 키보드가 움직이면 다시 기다린다)에만 열고, 그 전에는 소비하지 않는다. route 안에서만 쓴다. 핵심 포인트의 시간 안내는 들을 녹음이 있을 때만 뜨고, 없으면 소비하지 않는다.

## 호환

- 저장 키는 추가만 했다(`aido_coachmark_v1:{accountId}:ai-consent-*`·`voice-note-mark`·`repeat-horizon`, 말로 메모하기 초안·녹음).
