# 1.12.1 클라이언트: iPhone Duo·Mac 정리, SDK 58 정합성, 구조 정비

추적 이슈: #988 · 기준: `main` `ad575f4a`(1.12.0)

## 무엇을 바꿨나

일반 iPhone·Android 폰 사용자는 보이는 흐름이 거의 같다. 바뀌는 것은 폴더블·Duo·Mac 경험, 실제 버그, 그리고 내부 구조다.
로그인 토큰·저장 키, 서버 DTO, 푸시 payload, 위젯 URI(`aido://feed?…`, `aido://todo/{id}`), OAuth 주소(`aido://auth/callback`, `aido://auth/{provider}`)는 바꾸지 않았다. 이전 버전 앱과 기존 로그인 상태에 영향이 없다.

## 읽은 자료와 버린 대안

- [Supporting iPhone Duo](https://expo.dev/blog/supporting-iphone-duo), [How to upgrade to SDK 58](https://expo.dev/blog/how-to-upgrade-to-sdk-58)
- `expo-router` `SplitView`: 네이티브 내비게이터 안에서는 throw하고 iOS 전용이다. 우리 pane은 `NativeTabs` 안에 있어 쓰지 않았다.
- `@expo/ui` `ArrangementView`: iOS 27.1+ 전용이고 Android 대응이 없다.
- `useVerticalBarEdgeIOS`: Duo 감지 API가 아니다.
- 그래서 세 화면이 같은 계약으로 쓰는 `AdaptivePane`을 유지하고, 신호만 라이브러리(`react-native-reserved-regions`, `safe-area-context` `initialMetrics`, `expo-device`)에서 받는다. 접힘선은 `expo-hinge` 자세값으로 추정하지 않고 reserved region이 준 실제 위치를 쓴다(Expo 가이드가 소개하는 iOS 27.1 reserved regions, Android `FoldingFeature`).
- 시트를 네이티브 `formSheet`로 바꾸는 안은 키보드 추종 UX가 달라져 버렸다. 라우트(`transparentModal` + `animation: 'none'`) 안에서 기존 gorhom 시트를 그린다.

## 구조 변경 요약

- **Duo·Mac**: `useCompactDetailHandoff`(포커스 + compact일 때만), pane별 `SafeAreaProvider initialMetrics`, `IS_IOS_APP_ON_MAC`, 접힘선 위치로 pane 분할(`findVerticalFold`), 시트 배치(`getSheetLayout`).
- **라우팅**: 폴더는 리소스(`[todoId]`, `[memoId]`), 쿼리는 보기 상태. 각 param은 zod로 검증하는 튜플 훅으로 읽고, href는 기능별 순수 빌더가 만든다. 푸시는 `resolveNotificationDestination`이 모든 `NOTIFICATION_TYPE`을 새 경로로 해석한다.
- **컴포넌트 계약**: 목록은 자기 데이터를 구독하고 `.Item/.Loading/.Error/.Empty`를 같은 파일에 둔다. 선택 상세는 바깥이 id를 읽고 `.Contents`가 조회한다. 입력·시트는 원본 props(`value/onChange`, `isOpen/onOpenChange`)를 `Omit<ComponentProps>`로 잇는다.
- **상태**: 서버 상태는 TanStack Query, URL 상태는 Expo Router, pending·error는 mutation·RHF 값을 그대로 쓴다. 캐시 무효화는 `{feature}-cache.ts` 헬퍼로만 한다.
- **정리**: raw `View` → `Box/HStack/VStack`, "없음"은 `== null`, `as`·`any`·`!` 제거, 직접 만든 훅(`usePrefersReducedMotion`, `useClipboard`, `useStepper`)과 죽은 코드 삭제, 드래그 정렬을 shared 제네릭 하나로 통합.

## 라이브러리

- `npx expo install --fix`: `expo` 58.0.19, `expo-router` 58.0.26, `@expo/ui`·`expo-widgets` 등 58.0.23, `babel-preset-expo` 58.0.20. `expo-doctor` 20/20.
- 추가: `react-native-reserved-regions` 0.2.0(Expo Duo 가이드 권장), `react-native-reorderable-list` 0.18.2, `@expo/material-symbols`(Android 헤더 아이콘). 제거: `react-native-draggable-flatlist`와 60KB 호환 패치, `expo-symbols`, `@expo/dom-webview`, 읽히지 않던 `edgeToEdgeEnabled`.
- 같은 메이저 최신화: `es-toolkit` 1.53, `react-hook-form` 7.91, `i18next` 26.5.10, `react-i18next` 17.1.8.
- 올리지 않음: `zod`(서버와 공유, 4.3.6 고정), `@sentry/react-native`(전용 patch), Firebase 27·`@babel/runtime` 8(메이저).

## 운영 확인 사항

- Sentry `feature` 태그가 snake_case union으로 통일됐다. `app-version` → `app_version`. 이 값으로 거르는 대시보드·알림 규칙을 바꾼다.
- 시트와 피드가 라우트로 바뀌어 `screen_view` 화면 이름에 새 경로(`todo/[todoId]/actions` 등)가 생긴다. 친구 피드는 별도 화면 이름 대신 `feed`로 집계된다.
- 알림 제목은 개인정보라 로그에 남기지 않는다.
