# 전환 상태 (1.15.2 stack)

규칙 문서는 목표 모양이다. 아직 목표 모양이 아닌 코드는 이 표에만 적는다. 기능 PR이 끝나면 그 행을 지우고, lint baseline도 함께 줄인다. 표가 비면 이 파일을 지운다.

- 규칙: [structure](./structure.md), [model](./model.md), [data](./data.md), [state-and-routing](./state-and-routing.md), [hooks](./hooks.md), [ui](./ui.md), [ui-catalog](./ui-catalog.md)
- 진행 순서: 문서 → 가드레일 → 공용 기반 → `notification` → 기능별 → 마무리

## 가드레일 baseline

1.15.2 [13/32]에서 아래 규칙을 켜고 그때 위반을 baseline으로 남겼다(#1400). 기능 PR마다 그 기능의 baseline을 0으로 줄이고 이 표의 수를 고친다. 마지막 PR에서 모두 0인지 확인한다. 줄이는 방법은 [guardrails](./guardrails.md#baseline-1400)에 있다. 수는 지금 남은 위반이고(켤 때 [12/32] 위에서 잰 값에서 기능 PR이 줄인 만큼 뺐다) 괄호는 지시문 줄·파일 수다.
