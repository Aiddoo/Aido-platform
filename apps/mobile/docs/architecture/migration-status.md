# 전환 상태 (1.15.2 stack)

규칙 문서는 목표 모양이다. 아직 목표 모양이 아닌 코드는 이 표에만 적는다. 기능 PR이 끝나면 그 행을 지우고, lint baseline도 함께 줄인다. 표가 비면 이 파일을 지운다.

- 규칙: [structure](./structure.md), [model](./model.md), [data](./data.md), [state-and-routing](./state-and-routing.md), [hooks](./hooks.md), [ui](./ui.md), [ui-catalog](./ui-catalog.md)
- 진행 순서: 문서 → 가드레일 → 공용 기반 → `notification` → 기능별 → 마무리

## 기능별

| 기능                       | 남은 일                                                                                                                                                                                                                                                                                                                                                                                                                               |
| -------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `insights/report`          | 프리미엄 첫 리포트 전 `.Loading`(카드 3장) → `.Empty`(샘플 1장+문구) 높이 차이                                                                                                                                                                                                                                                                                                                                                        |
| `planning/todo`·`composer` | 내 피드 스크롤이 `ScrollViewContainer`(재정렬 목록)라 `SafeAreaScrollView`가 아님                                                                                                                                                                                                                                                                                                                                                     |
| `voice`                    | 한 파일만 쓰지만 테스트가 붙은 상태 기계 훅 5개(`useVoiceNoteRecording`·`useVoiceNoteDigest`·`useDictation`·`useVoiceNoteCaptions`·`useOfferOnDeviceModel`)를 `hooks/`에 둠                                                                                                                                                                                                                                                           |
| `billing/subscription`     | 결제 화면 `ScrollView` 3개(영수증·시작 화면·요금제 뼈대), `useSubscriptionReceipt`가 내 정보를 다시 suspend(PlanSummary 등 호출부가 많아 인자로 바꾸지 않음)                                                                                                                                                                                                                                                                          |
| `social/*`                 | `InviteCodePolicy`(원문 문자열을 받는 함수, Policy 밖으로), `nudge-interaction` Policy 3개 한 파일(→ 엔티티별), `TodoReportPolicy` 이름, 친구 검색창(`Stack.SearchBar`)은 `autoCorrect`를 받지 않아 자동 수정을 끌 수 없다. 친구 목록 행은 친구 피드로 가는 `Link` + `Link.Menu`(피드는 다른 탭이라 미리보기 없음)이고, 피드의 친구 줄은 같은 화면의 세터, 초대한 친구 행은 상세 route가 없고 콕이 버튼 동작이라 `Link` 대상이 아니다 |
| `device/*`                 | iOS에서 위젯 저장소가 no-op인데 그 위에 navigation repository·헤드리스 실패 읽기를 두는 것(동작 영향 없음)                                                                                                                                                                                                                                                                                                                            |

## 1.15.2에서 바꾸지 않기로 한 것

리뷰에서 정한 대로 아래 셋은 이번에 바꾸지 않는다. 바꾸려면 이슈로 따로 정한다.

- 무한 목록의 `maxPages`(쌓아 두는 쪽 수 상한)
- 반복 할 일 격주의 기준 주
- 서버 푸시의 12·24시간 기준
