# 1.13.0 화면 목록

`apps/mobile/app/`(Expo Router)의 사용자 화면·시트·대화상자·상태를 모두 적었다. **번호**가 있는 행은 `capture.sh`가
`NN_화면명.png`로 자동 캡처한다. 번호가 `—`인 행은 자동 캡처하지 않으며 이유를 상태 열에 적었다.
경로는 딥링크(`aido-dev://<경로>`) 기준이다. 일반 = 무료 계정, 프리미엄 = 스토어 구독 + 초대 보상 BANKED 계정.
